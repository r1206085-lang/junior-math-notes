一元二次方程式：三大解法與判別式全攻略

當方程式出現 $x^2$ 時，答案通常有兩個！掌握「因式分解法」、「配方法」與萬能「公式解 $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$」，解決花園開闢步道與商品漲價利潤應用題！

🎯 本單元核心學習目標

  • ✓理解零乘積性質：若 $A \times B = 0$，則 $A = 0$ 或 $B = 0$，並用因式分解法快速求解。
  • ✓學會配方法（兩邊同加「一次項係數一半的平方」），湊成完全平方式 $(x+p)^2 = q$。
  • ✓熟記一元二次方程式公式解與判別式 $D = b^2 - 4ac$（判斷兩相異實根、重根或無實數解）。
  • ✓能將花園步道平移合併法與商品售價漲降問題列成一元二次方程式，並檢驗解的合理性。

生活化比喻：歸零炸彈（$A \times B = 0$）與花園步道推到邊邊

為什麼解一元二次方程式一定要先讓等號右邊變成 $0$？花園十字步道題怎麼一秒列式？

💣 比喻一：只有「等於 $0$」才能推理！

為什麼 $(x-2)(x-3) = 6$ 不能直接說 $x-2=6$？

  • 因為兩個數相乘等於 $6$ 有無限多種可能（$1\times 6, 2\times 3, 12\times 0.5\dots$）！
  • 但唯獨兩數相乘等於 $0$（$A \times B = 0$）時，其中至少有一個數必然是「歸零炸彈 $0$」！所以解一元二次方程式的第一步：永遠先把所有項移到左邊，讓等號右邊變成 $0$！

🌷 比喻二：長方形花園開闢十字步道「全部推到邊角合併」

長 $20$ 公尺、寬 $15$ 公尺的花園，中間開闢寬為 $x$ 公尺的十字形道路，剩餘花圃面積怎麼算最快？

  • 別傻傻切四塊再扣重疊正方形！想像把水平道路推到最底下、垂直道路推到最右邊！
  • 剩下的四塊花圃瞬間合體成一個長為 $(20 - x)$、寬為 $(15 - x)$ 的完整長方形，直接列式 $(20-x)(15-x) = \text{花圃面積}$ 秒殺！

核心公式表格與常見易錯提醒

因式分解法、配方法、公式解與判別式 $D = b^2 - 4ac$ 總整理

核心概念 數學公式與步驟 判別條件與說明
因式分解法 $$(ax - b)(cx - d) = 0 \implies x = \frac{b}{a} \text{ 或 } \frac{d}{c}$$ 逆推：若已知兩根為 $\alpha, \beta$，可還原方程式為 $(x-\alpha)(x-\beta) = 0$。
配方法口訣 $$x^2 + bx + \left(\frac{b}{2}\right)^2 = \left(x + \frac{b}{2}\right)^2$$ 前提：二次項係數必須先化為 $1$，再於等號兩邊同加「一次項係數一半的平方」。
萬能公式解 $$ax^2 + bx + c = 0 \quad (a \ne 0)$$ $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$ 當十字交乘法拆不開時，直接代公式解！
判別式 $D = b^2 - 4ac$ • $b^2 - 4ac > 0$：兩相異實根
• $b^2 - 4ac = 0$：兩相等實根（重根 $x = -\frac{b}{2a}$）
• $b^2 - 4ac < 0$：無實數解（無解） 		看到題目說「方程式有重根（或恰有一解）」，立刻列式 $b^2 - 4ac = 0$！

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「解 $x(x - 3) = 2(x - 3)$ 時，左右直接把 $(x - 3)$ 約掉得 $x = 2$！」

直接約掉含未知數的因式，會導致漏掉一個根 $x = 3$！

✅ 正確觀念：千萬不可隨便除以可能為 $0$ 的 $(x-3)$！應移項提公因式：$(x-3)(x-2)=0 \implies x = 3 \text{ 或 } 2$。

❌ 錯誤迷思 2：「應用題算出兩個正數解都保留」

例如寬 $15$ 公尺的花園開闢路寬 $x$，解出 $x = 3$ 或 $x = 32$ 忘記檢查。

✅ 正確觀念：路寬 $32$ 公尺比花園原本的寬 $15$ 公尺還大，顯然不合！務必標註「$32$ 不合」。

✍️

經典題型演練（點擊展開逐步詳解）

涵蓋公式解、重根判別式與花園步道面積應用題

基礎題 公式解求解一元二次方程式

1. 解一元二次方程式：$$2x^2 - 4x - 1 = 0$$

🔍 點擊展開逐步詳解▼

步驟 1：判別式 $D = b^2 - 4ac = (-4)^2 - 4(2)(-1) = 16 + 8 = 24$

步驟 2：代入公式解並約分化簡

$$x = \frac{-(-4) \pm \sqrt{24}}{2 \times 2} = \frac{4 \pm 2\sqrt{6}}{4} = \frac{2 \pm \sqrt{6}}{2}$$

答：$x = \frac{2 \pm \sqrt{6}}{2}$

進階段考題 重根與判別式 $b^2 - 4ac = 0$

2. 若 $x$ 的一元二次方程式 $x^2 - (k + 2)x + 9 = 0$ 有重根（兩相等實根），求 $k$ 的所有可能值為何？

🔍 點擊展開逐步詳解▼

步驟 1：由重根條件列判別式 $b^2 - 4ac = 0$

$$[-(k + 2)]^2 - 4(1)(9) = 0 \implies (k + 2)^2 = 36$$

步驟 2：兩邊開平方根求解（注意有正負兩解！）

$$k + 2 = \pm 6 \implies k = 4 \text{ 或 } -8$$

答：$k = 4 \text{ 或 } -8$。

會考素養題 花園開闢十字形步道問題

3. 有一塊長 $20$ 公尺、寬 $14$ 公尺的長方形草地，今在內部開闢一橫一豎且等寬的十字形步道，使剩餘草地的總面積為 $216$ 平方公尺，請問步道的寬度為多少公尺？

🔍 點擊展開逐步詳解▼

步驟 1：設步道寬為 $x$ 公尺，將步道平移至邊界後列面積方程式

$$(20 - x)(14 - x) = 216$$

步驟 2：展開並整理為標準式做十字交乘

$$280 - 34x + x^2 = 216 \implies x^2 - 34x + 64 = 0$$

$$(x - 2)(x - 32) = 0 \implies x = 2 \text{ 或 } 32\text{（大於寬 } 14 \text{ 不合）}$$

答：步道的寬度為 $2$ 公尺。
