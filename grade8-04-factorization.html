因式分解：提公因式、乘法公式與十字交乘法

如果「展開多項式」是把長方形切成零碎的小拼圖，那麼「因式分解」就是把散落的拼圖重新拼回一個完整的大長方形，找出它的長與寬！

🎯 本單元核心學習目標

  • ✓理解因式分解就是將多項式的加減和差形式化為非零次多項式的連乘積。
  • ✓熟練因式分解第一守則：「先提公因式（包含變號提公因式 $b - a = -(a - b)$）」。
  • ✓逆向運用三大乘法公式（平方差、和的平方、差的平方）快速分解二次多項式。
  • ✓精通十字交乘法口訣：「拆兩頭、湊中間、橫著寫」。
💡

生活化比喻：拼圖面積重組與十字交乘對角線湊數

為什麼 $x^2 + 5x + 6$ 可以分解成 $(x+2)(x+3)$？用長方形拼圖一眼看穿！

🧩 比喻一：拼圖面積重組（找回長方形的長與寬）

手上有 $1$ 張 $x^2$ 大正方形、$5$ 張面積為 $x$ 的長條形、$6$ 張面積為 $1$ 的小正方形：

  • 把 $6$ 張小正方形排成「$2 \times 3$」陣列，並將 $5x$ 拆成「$2x$ 與 $3x$」鑲嵌在旁邊，就能完美拼成一個長為 $(x+3)$、寬為 $(x+2)$ 的大長方形！
  • 總面積恆等式：$$x^2 + 5x + 6 = (x + 2)(x + 3)$$

⚔️ 比喻二：十字交乘法口訣「拆兩頭、湊中間、橫著寫」

把拼圖濃縮成十字架配對：

  • 左列拆二次項（$x^2 = x \cdot x$），右列拆常數項（$+6 = (+2)\times(+3)$）。
  • 交叉相乘相加：$3x + 2x = +5x$（命中中間項！），直接橫著寫成 $(x+2)(x+3)$！
📘

因式分解四大招式與正負號判定表

按照「一提、二套、三十字、四分組」順序思考

分解招式 標準代數公式 破題技巧與範例
1. 提公因式法 $$AB + AC = A(B + C)$$ $$(b - a) = -(a - b), \quad (b - a)^2 = (a - b)^2$$ 永遠第一步！例：$3x(x-2) + 5(2-x) = (x-2)(3x-5)$。
2. 乘法公式法 $$a^2 - b^2 = (a + b)(a - b)$$ $$a^2 \pm 2ab + b^2 = (a \pm b)^2$$ 兩項看平方差；三項且頭尾為平方數看完全平方。
3. 十字交乘法 $$x^2 + (p+q)x + pq = (x + p)(x + q)$$ $$acx^2 + (ad+bc)x + bd = (ax + b)(cx + d)$$ 常數項為 $+$ 拆同號；常數項為 $-$ 拆異號。

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「把提出的數字公因數直接丟掉！」

分解 $2x^2 - 10x + 12$ 時誤寫成 $(x-2)(x-3)$。

✅ 正確觀念：因式分解不是解方程式，提出的公因數 $2$ 必須保留在最前面：$2(x-2)(x-3)$！

❌ 錯誤迷思 2：「分解不徹底」

將 $x^4 - 16$ 寫成 $(x^2+4)(x^2-4)$ 就停筆。

✅ 正確觀念：$(x^2-4)$ 還能用平方差繼續分解為 $(x+2)(x-2)$，完整答案為 $(x^2+4)(x+2)(x-2)$。

✍️

經典題型演練（點擊展開逐步詳解）

涵蓋十字交乘、提公因式與幾何拼圖周長應用

基礎題 十字交乘法

1. 因式分解多項式：$$x^2 - 4x - 21$$

🔍 點擊展開逐步詳解▼

將 $-21$ 拆成 $(-7) \times (+3)$，交叉相乘得 $-7x + 3x = -4x$，故原式 $= (x - 7)(x + 3)$。

答：$(x - 7)(x + 3)$

進階段考題 先提公因式再十字交乘

2. 因式分解多項式：$$6x^2 - 14x - 12$$

🔍 點擊展開逐步詳解▼

先提公因數 $2$ 得 $2(3x^2 - 7x - 6)$，再用十字交乘分解括號內得 $2(3x + 2)(x - 3)$。

答：$2(3x + 2)(x - 3)$

會考素養題 拼圖面積重組求周長

3. 用 $2$ 張面積為 $x^2$ 的正方形、$11$ 張面積為 $x$ 的長方形與 $12$ 張面積為 $1$ 的小正方形，緊密拼成一個大長方形，則此大長方形的「周長」以 $x$ 的多項式表示為何？

🔍 點擊展開逐步詳解▼

總面積 $= 2x^2 + 11x + 12 = (2x + 3)(x + 4)$，故長寬分別為 $2x+3$ 與 $x+4$。

周長 $= 2[(2x+3) + (x+4)] = 6x + 14$。

答：$6x + 14$
