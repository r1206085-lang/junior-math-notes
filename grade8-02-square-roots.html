平方根與根號運算：最簡根式與有理化秘笈

當正方形面積是 $7$ 時，它的邊長是多少？認識全新符號「根號 $\sqrt{a}$」，釐清「$\sqrt{a}$」與「$a$ 的平方根（$\pm\sqrt{a}$）」的差別，並掌握最簡根式與分母有理化！

生活化比喻：雙胞胎結伴出獄與夾三明治估計法

為什麼 $\sqrt{12}$ 可以化簡成 $2\sqrt{3}$？怎麼一秒鐘知道 $\sqrt{30}$ 大約是幾點幾？

👯 比喻一：根號監獄的「雙胞胎出獄規則」

把根號 $\sqrt{\quad}$ 想像成一間房間，規定「要湊滿兩個一模一樣的質因數（平方），才能合體成一個走出根號外面」：

  • 化簡 $\sqrt{18}$：做標準分解式 $18 = 2 \times 3^2$。
  • 裡面的兩個 $3$（$3^2$）湊成一對，走出根號變成一個 $3$；落單的 $2$ 只能留在根號內： $$\sqrt{18} = \sqrt{3^2 \times 2} = 3\sqrt{2}$$

🥪 比喻二：完全平方數「三明治夾擊法」

想知道 $\sqrt{30}$ 是幾點多？只要找出 $30$ 左右兩邊最近的完全平方數（$25$ 與 $36$）：

  • 因為 $\sqrt{25} < \sqrt{30} < \sqrt{36}$，也就是 $5 < \sqrt{30} < 6$！
  • 立刻得知 $\sqrt{30} = 5.\text{多}$，它的整數部分是 $5$，小數部分就是 $(\sqrt{30} - 5)$！

核心公式表格與常見易錯提醒

平方根定義、根式乘除與分母有理化完整對照表

核心概念 數學公式與性質 關鍵說明與範例
正數 $a$ 的平方根 若 $x^2 = a \quad (a > 0)$，則 $x = \pm\sqrt{a}$ 正數的兩個平方根互為相反數，相加必為 $0$；$0$ 的平方根只有 $0$；負數沒有實數平方根。
平方開根號性質 $$\sqrt{a^2} = |a| = \begin{cases} a, & a \ge 0 \\ -a, & a < 0 \end{cases}$$ 例：$\sqrt{(-7)^2} = |-7| = 7$（絕對不會等於 $-7$！）。
根式的乘除法則 $$\sqrt{a} \times \sqrt{b} = \sqrt{ab}, \quad \frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}} \quad (a \ge 0, b > 0)$$ 同類方根才能相加減：$3\sqrt{2} + 5\sqrt{2} = 8\sqrt{2}$，但 $\sqrt{2} + \sqrt{3}$ 不能合併！
雙項分母有理化 $$\frac{c}{\sqrt{a} - \sqrt{b}} = \frac{c(\sqrt{a} + \sqrt{b})}{(\sqrt{a}-\sqrt{b})(\sqrt{a}+\sqrt{b})} = \frac{c(\sqrt{a} + \sqrt{b})}{a - b}$$ 利用平方差公式消去分母根號。
例：$\frac{1}{\sqrt{5}-2} = \frac{\sqrt{5}+2}{5-4} = \sqrt{5}+2$。

⚠️ 常見易錯觀念提醒（必考陷阱！）

❌ 錯誤迷思 1：「$\sqrt{16} = \pm 4$」或「$\sqrt{16}$ 的平方根是 $\pm 4$」

全台灣八年級第一次段考錯誤率高達 70% 的文字陷阱題！

✅ 正確觀念：符號 $\sqrt{16}$ 前面沒有負號，本身就等於 $+4$！所以題目問「$\sqrt{16}$ 的平方根」，其實是在問「$4$ 的平方根」，答案是 $\pm\sqrt{4} = \pm 2$！

❌ 錯誤迷思 2：「$\sqrt{2} + \sqrt{3} = \sqrt{5}$」

把根號內的數字直接相加減。

✅ 正確觀念：不同類方根就像 $x + y$ 一樣絕對不能相加減！$\sqrt{2} + \sqrt{3}$ 已經是最簡結果。

經典題型演練（點擊展開逐步詳解）

涵蓋最簡根式化簡、兩個平方根性質與雙項分母有理化

基礎題 最簡根式與同類方根加減

1. 化簡下列根式運算：$$\sqrt{27} - \sqrt{12} + \frac{6}{\sqrt{3}}$$

🔍 點擊展開逐步詳解▼

步驟 1：將各項分別化為最簡根式並有理化分母

• $\sqrt{27} = \sqrt{9 \times 3} = 3\sqrt{3}$

• $\sqrt{12} = \sqrt{4 \times 3} = 2\sqrt{3}$

• $\frac{6}{\sqrt{3}} = \frac{6\sqrt{3}}{3} = 2\sqrt{3}$

步驟 2：合併同類方根

$$\text{原式} = 3\sqrt{3} - 2\sqrt{3} + 2\sqrt{3} = 3\sqrt{3}$$

答：$3\sqrt{3}$

進階段考題 正數的兩個平方根互為相反數

2. 已知某正數 $N$ 的兩個平方根分別為 $(2x - 1)$ 與 $(-x - 5)$，求此正數 $N$ 的值為何？

🔍 點擊展開逐步詳解▼

步驟 1：利用「同一個正數的兩個平方根必互為相反數（相加 $= 0$）」求 $x$

$$(2x - 1) + (-x - 5) = 0 \implies x - 6 = 0 \implies x = 6$$

步驟 2：代回求出平方根，再平方還原正數 $N$

平方根為 $2(6) - 1 = 11$（與 $-11$），故原正數 $N = 11^2 = 121$。

答：$N = 121$。

會考素養題 雙項分母有理化與乘法公式結合

3. 計算並化簡：$$\frac{4}{\sqrt{7} - \sqrt{3}} - (\sqrt{7} - \sqrt{3})^2$$

🔍 點擊展開逐步詳解▼

步驟 1：有理化第一項（上下同乘 $\sqrt{7} + \sqrt{3}$）

$$\frac{4(\sqrt{7} + \sqrt{3})}{(\sqrt{7})^2 - (\sqrt{3})^2} = \frac{4(\sqrt{7} + \sqrt{3})}{7 - 3} = \sqrt{7} + \sqrt{3}$$

步驟 2：展開第二項完全平方

$$(\sqrt{7} - \sqrt{3})^2 = 7 - 2\sqrt{21} + 3 = 10 - 2\sqrt{21}$$

步驟 3：合併相減

$$\text{原式} = \sqrt{7} + \sqrt{3} - 10 + 2\sqrt{21}$$

答：$\sqrt{7} + \sqrt{3} + 2\sqrt{21} - 10$。
