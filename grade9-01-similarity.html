圖形的相似形與比例線段：縮放世界的幾何法則

從手機雙指縮放照片到 Google Maps 地圖比例尺，當圖形等比例放大或縮小時，角度發生了什麼變化？邊長與面積又遵循什麼倍數規律？一起掌握九年級幾何會考壓軸核心！

🎯 本單元核心學習目標

  • ✓ 理解多邊形相似的雙重條件：「對應角相等」且「對應邊成比例」（兩者缺一不可）。
  • ✓ 掌握平行線截比例線段性質，以及三角形兩邊中點連線性質（$\overline{DE} = \frac{1}{2}\overline{BC}$）。
  • ✓ 熟練三角形三大相似性質（$AA$ 相似、$SAS$ 相似、$SSS$ 相似）的判別與幾何推理。
  • ✓ 活用相似形的面積比等於對應邊長平方比（$a^2 : b^2$），以及利用竿影立竿見影測量高塔。

生活化比喻：手機照片放大縮小與地圖比例尺

為什麼照片放大 2 倍，裡面的屋頂角度不會變大 2 倍，但洗出來的相紙面積卻變 4 倍？

📱 比喻一：手機雙指縮放照片（維持形狀不變形）

當你在手機相簿用兩根手指把一張三角形屋頂的照片等比例放大 $2$ 倍時：

  • 對應角完全不變：原本 $60^\circ$ 的屋頂尖角，放大後依然是 $60^\circ$（如果變成 $120^\circ$，屋頂就扁掉了！）。
  • 對應邊長同乘 $2$ 倍：屋簷、柱子、窗框的長度全部變成原來的 $2$ 倍（對應邊成比例）。
  • 反例警告：如果只拉寬不拉高（像把 4:3 照片硬拉成 16:9 寬螢幕），人臉會變胖變扁，這就不是相似形！

🗺️ 比喻二：Google 地圖比例尺與面積平方倍定律

地圖就是真實世界縮小後的「相似圖形」：

  • 若地圖比例尺為 $1 : 5000$，代表地圖上 $1\text{ cm}$ 的道路，實際長度是 $5000\text{ cm} = 50\text{ m}$。
  • 面積要平方倍！如果把邊長 $1\text{ cm}$ 的正方形瓷磚放大 $3$ 倍，新正方形的長變 $3$ 倍、寬也變 $3$ 倍，可以塞進 $3 \times 3 = 9$ 塊原瓷磚！
  • 因此：相似圖形的周長比 $=$ 對應邊長比（$a : b$）；但面積比 $=$ 對應邊長的平方比（$a^2 : b^2$）！

會考幾何必考雙模型：當 $\overline{DE} \parallel \overline{BC}$ 時，秒出 $\triangle ADE \sim \triangle ABC$ (AA 相似)

🔺 模型 A：金字塔型（A 字型平行截線）

在 $\triangle ABC$ 內部畫一條平行底邊的線段 $\overline{DE} \parallel \overline{BC}$：

• 左右截線比：$\overline{AD} : \overline{DB} = \overline{AE} : \overline{EC}$
• 含底邊全體比：$\overline{AD} : \overline{AB} = \overline{AE} : \overline{AC} = \overline{DE} : \overline{BC}$

⏳ 模型 B：沙漏型（8 字型平行內錯角）

上下兩平行線 $\overline{DE} \parallel \overline{BC}$ 被兩條交叉直線連接於頂點 $A$：

• 因為內錯角相等 + 對頂角相等 $\implies \triangle ADE \sim \triangle ABC$
• 對應邊成比例：$\overline{AD} : \overline{AB} = \overline{AE} : \overline{AC} = \overline{DE} : \overline{BC}$

核心公式表格與常見易錯提醒

三角形相似性質、比例線段、中點連線與直角母子相似定理一覽表

核心概念 數學公式與幾何性質 關鍵條件與應用情境
三角形三大相似性質 1. $AA$ 相似：兩組對應角相等（最常用！）
2. $SAS$ 相似：兩組對應邊成比例，且夾角相等
3. $SSS$ 相似：三組對應邊皆成比例 		三角形只要滿足其中一項即相似；但四邊形以上必須同時檢查「對應角相等」與「對應邊成比例」。
平行線截比例線段 在 $\triangle ABC$ 中，若 $\overline{DE} \parallel \overline{BC}$，則：
$$\frac{\overline{AD}}{\overline{DB}} = \frac{\overline{AE}}{\overline{EC}} \quad \text{且} \quad \frac{\overline{AD}}{\overline{AB}} = \frac{\overline{AE}}{\overline{AC}} = \frac{\overline{DE}}{\overline{BC}}$$ 		特別注意：求中間平行底邊 $\overline{DE}$ 時，必須用小三角形全邊 $\overline{AD}$ 比大三角形全邊 $\overline{AB}$！
三角形兩邊中點連線 若 $D, E$ 分別為 $\overline{AB}, \overline{AC}$ 的中點，則：
$$\overline{DE} \parallel \overline{BC} \quad \text{且} \quad \overline{DE} = \frac{1}{2}\overline{BC}$$ 		推廣：任意四邊形四邊中點依序連線，必形成一個平行四邊形，且其周長等於原四邊形兩對角線長之和。
相似形的邊長、面積與體積比 若相似圖形（或相似立體圖形）對應邊長比為 $a : b$：
• 對應高、角平分線、中線、周長比 $= a : b$
• 面積比（表面積比） $= a^2 : b^2$
• 體積比 $= a^3 : b^3$ 		例：兩相似圓錐對應高之比為 $2 : 5$，則周長比為 $2 : 5$，表面積比為 $2^2 : 5^2 = 4 : 25$，體積比為 $2^3 : 5^3 = 8 : 125$。
直角三角形母子相似 $\angle BAC = 90^\circ$，$\overline{AD} \perp \overline{BC}$ 於 $D$：
• $\overline{AD}^2 = \overline{BD} \times \overline{CD}$
• $\overline{AB}^2 = \overline{BD} \times \overline{BC}$，$\overline{AC}^2 = \overline{CD} \times \overline{BC}$ 		因為 $\triangle DBA \sim \triangle DAC \sim \triangle ABC$（皆為 $AA$ 相似）。

⚠️ 常見易錯觀念提醒（九年級段考與會考經典陷阱）

❌ 錯誤迷思 1：「把 $\overline{AD} : \overline{DB}$ 直接當成 $\overline{DE} : \overline{BC}$！」

已知 $\overline{AD} : \overline{DB} = 2 : 3$，就誤以為平行底邊比 $\overline{DE} : \overline{BC}$ 也是 $2 : 3$。

✅ 正確觀念：$\overline{DB}$ 只是下半截梯形的腰，不是大三角形的邊！大三角形的邊長是 $\overline{AB} = 2 + 3 = 5$ 份，故 $\overline{DE} : \overline{BC} = \overline{AD} : \overline{AB} = 2 : 5$！

❌ 錯誤迷思 2：「兩個長方形（或兩個菱形）一定相似」

以為長方形四個角都是 $90^\circ$ 就相似，或菱形四邊等長就相似。

✅ 正確觀念：長方形只滿足對應角相等，長寬比不一定相同；菱形只滿足對應邊成比例，內角不一定相等。正多邊形（如兩個正方形、兩個正三角形）才一定相似！

經典題型演練（點擊展開逐步詳解）

精選平行截線、面積平方比與太陽影長測量大樓高度三道代表題

基礎題 平行線截比例線段與底邊比

1. 在 $\triangle ABC$ 中，$D$、$E$ 分別為 $\overline{AB}$、$\overline{AC}$ 上的點，且 $\overline{DE} \parallel \overline{BC}$。已知 $\overline{AD} = 6$、$\overline{DB} = 9$、$\overline{BC} = 20$，請問線段 $\overline{DE}$ 的長度是多少？

🔍 點擊展開逐步詳解 ▼

步驟 1：先算出大三角形的完整側邊長 $\overline{AB}$

$$\overline{AB} = \overline{AD} + \overline{DB} = 6 + 9 = 15$$

步驟 2：利用 $\triangle ADE \sim \triangle ABC$（$AA$ 相似）列出對應邊比例式

$$\frac{\overline{DE}}{\overline{BC}} = \frac{\overline{AD}}{\overline{AB}}$$

$$\frac{\overline{DE}}{20} = \frac{6}{15} = \frac{2}{5}$$

步驟 3：交叉相乘求解 $\overline{DE}$

$$\overline{DE} = 20 \times \frac{2}{5} = 8$$

答：$\overline{DE} = 8$。

進階段考題 相似三角形面積比與梯形面積切割

2. 承上題圖形，在 $\triangle ABC$ 中，$\overline{DE} \parallel \overline{BC}$，且 $\overline{AD} : \overline{DB} = 2 : 3$。若小三角形 $\triangle ADE$ 的面積為 $16\text{ cm}^2$，請問下半部四邊形 $DBCE$（梯形）的面積是多少 $\text{cm}^2$？

🔍 點擊展開逐步詳解 ▼

步驟 1：找出相似三角形 $\triangle ADE$ 與 $\triangle ABC$ 的對應邊長比

$$\overline{AD} : \overline{AB} = 2 : (2 + 3) = 2 : 5$$

步驟 2：利用「面積比 $=$ 對應邊長的平方比」求 $\triangle ABC$ 總面積

$$\triangle ADE \text{ 面積} : \triangle ABC \text{ 面積} = 2^2 : 5^2 = 4 : 25$$

$$16 : \triangle ABC \text{ 面積} = 4 : 25 \implies \triangle ABC \text{ 面積} = 16 \times \frac{25}{4} = 100\text{ cm}^2$$

步驟 3：用大三角形面積扣除小三角形面積，即得梯形 $DBCE$ 面積

$$\text{四邊形 } DBCE \text{ 面積} = 100 - 16 = 84\text{ cm}^2$$

答：四邊形 $DBCE$ 的面積為 $84\text{ cm}^2$。

會考素養題 立竿見影與地圖比例尺測量應用

3. 同一時刻下，太陽光線視為平行光。身高 $160$ 公分的小妍站在操場上，測得自己在地面上的影子長為 $240$ 公分；若此時操場旁一棟教學大樓在地面上的影子長為 $18$ 公尺，請問這棟教學大樓的實際高度是多少公尺？

🔍 點擊展開逐步詳解 ▼

步驟 1：建立相似直角三角形模型（$AA$ 相似）

人與大樓皆垂直於地面（$90^\circ$），且同一時刻太陽光入射角相等，故「人高、人影與光線」構成的直角三角形，與「樓高、樓影與光線」構成的直角三角形必為 $AA$ 相似！

步驟 2：先求小妍的「實物高度 : 影子長度」最簡整數比

$$\text{高度} : \text{影長} = 160\text{ cm} : 240\text{ cm} = 2 : 3$$

步驟 3：設教學大樓實際高度為 $x$ 公尺，列比例式求解

$$x : 18 = 2 : 3$$

$$3x = 36 \implies x = 12 \text{（公尺）}$$

答：教學大樓的實際高度為 $12$ 公尺。
