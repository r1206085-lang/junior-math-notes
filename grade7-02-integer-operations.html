整數的運算：四則混合運算與指數律

理解「負負得正」背後的邏輯，熟練正負整數加減乘除與括號優先順序，並掌握將連乘積化繁為簡的五大指數律！

🎯 本單元核心學習目標

  • ✓熟練正負整數的加減法則（減去一個數等於加上它的相反數：$a - b = a + (-b)$）。
  • ✓掌握正負數乘除的符號法則：「同號相乘除得正、異號相乘除得負」。
  • ✓遵循四則混合運算順序：先算指數與括號（小 $\to$ 中 $\to$ 大），再先乘除後加減。
  • ✓理解底數與指數的意義，活用五大指數律處理同底數冪次的乘除運算。

生活化比喻：冷熱魔法石與細胞分裂倍增

為什麼「減去負數」反而變大？指數律為什麼相乘變相加？

🍲 比喻一：魔法湯鍋裡的「火石（$+$）」與「冰塊（$-$）」

把湯鍋溫度當作數值，加入為 $+$、撈出為 $-$：

  • 加入冰塊：$20 + (-5) = 15^\circ\text{C}$（溫度下降 $5$ 度）。
  • 撈出冰塊（負負得正）：$20 - (-5) = 20 + 5 = 25^\circ\text{C}$！把鍋子裡的冰塊拿走，湯鍋溫度當然會上升！
  • 同樣地，在帳單上「取消（$-$）一筆負債（$-100$ 元）」，就相當於你的財產增加了 $+100$ 元！

🦠 比喻二：細胞分裂倍增器（指數律 $a^m \times a^n = a^{m+n}$）

一顆細胞每小時分裂成 $2$ 顆：

  • 前 $3$ 小時分裂了 $2^3 = 2 \times 2 \times 2 = 8$ 倍。
  • 接著再經過 $4$ 小時，又分裂了 $2^4 = 16$ 倍。
  • 總共經過 $3 + 4 = 7$ 小時，總倍數就是把乘號串在一起： $$2^3 \times 2^4 = \underbrace{(2\times 2\times 2)}_{3\text{個}} \times \underbrace{(2\times 2\times 2\times 2)}_{4\text{個}} = 2^{3+4} = 2^7$$

核心公式表格與常見易錯提醒

整數四則運算定律與五大指數律完整對照表

公式名稱 數學公式表達 口訣與計算實例
整數減法轉加法 $$a - b = a + (-b)$$ $$a - (-b) = a + b$$ 減去一數 $=$ 加上其相反數。
例：$(-8) - (-15) = -8 + 15 = 7$
乘法對加減分配律 $$a \times (b \pm c) = a \times b \pm a \times c$$ 反向提公因數可秒殺速算：
$(-37)\times 99 + (-37)\times 1 = -37\times(99+1) = -3700$
指數律 (1)(2)
同底數相乘與相除		 $$a^m \times a^n = a^{m+n}$$ $$a^m \div a^n = a^{m-n} \quad (a \ne 0)$$ 底數相同：相乘指數相加，相除指數相減。
特別規定：當 $a \ne 0$ 時，$a^0 = 1$。
指數律 (3)(4)(5)
次方再次方與積的次方		 $$(a^m)^n = a^{m \times n}$$ $$(a \times b)^m = a^m \times b^m$$ 括號內外次方相乘；積的次方各自次方。
例：$(2^3)^4 = 2^{12}$；$(-2x)^3 = (-2)^3 x^3 = -8x^3$

⚠️ 常見易錯觀念提醒（段考必考陷阱！）

❌ 錯誤迷思 1：「$(-3)^4$ 與 $-3^4$ 答案一樣都是 $81$」

忽略了負號有沒有被括號包起來！

✅ 正確觀念：$(-3)^4 = (-3)\times(-3)\times(-3)\times(-3) = +81$（負號連乘 $4$ 次）；但 $-3^4 = -(3\times 3\times 3\times 3) = -81$（只有 $3$ 四次方，負號在外面）！

❌ 錯誤迷思 2：「$2^3 + 2^4 = 2^7$ 或 $2^3 = 6$」

把指數律套用到「加法」，或把次方當成底數乘指數。

✅ 正確觀念：指數律只適用於「乘除」！遇到加減法必須分別算出數值再相加：$2^3 + 2^4 = 8 + 16 = 24 \ne 128$。

經典題型演練（點擊展開逐步詳解）

檢驗四則混合運算順序、分配律速算與指數律化簡能力

基礎題 含指數與括號的四則混合運算

1. 計算下列算式的值：$$(-2)^4 - (-3^2) \times [5 - (-2)^3 \div 4]$$

🔍 點擊展開逐步詳解▼

步驟 1：先處理所有次方項（特別注意括號位置！）

$(-2)^4 = 16$，$-3^2 = -9$，$(-2)^3 = -8$

步驟 2：代回原式，先算中括號內的除法

$$\text{原式} = 16 - (-9) \times [5 - (-8) \div 4]$$

$$= 16 - (-9) \times [5 - (-2)] = 16 - (-9) \times 7$$

步驟 3：先乘除後加減

$$= 16 - (-63) = 16 + 63 = 79$$

答：$79$

進階段考題 指數律換底化簡

2. 若 $4^5 \times 8^2 \div 2^3 = 2^k$，請問 $k$ 的值為何？

🔍 點擊展開逐步詳解▼

步驟 1：將底數 $4$ 與 $8$ 全部統一換成以 $2$ 為底數

因為 $4 = 2^2$、$8 = 2^3$，所以：

$$4^5 = (2^2)^5 = 2^{10}$$

$$8^2 = (2^3)^2 = 2^6$$

步驟 2：運用同底數乘除指數律（相乘指數相加、相除指數相減）

$$2^{10} \times 2^6 \div 2^3 = 2^{10 + 6 - 3} = 2^{13}$$

答：$k = 13$

會考素養題 正負得分與倒扣計分問題

3. 某次數學競試共有 $25$ 題選擇題，計分規則為：答對一題得 $4$ 分，答錯一題倒扣 $1$ 分（即得 $-1$ 分），未作答得 $0$ 分。若阿哲在這次測驗中答對 $19$ 題、有 $2$ 題未作答，其餘皆答錯，請問阿哲的總得分為幾分？

🔍 點擊展開逐步詳解▼

步驟 1：先算出答錯的題數

$\text{答錯題數} = 25 - 19 - 2 = 4$ 題。

步驟 2：列出正負整數四則算式求總分

$$\text{總分} = 19 \times 4 + 2 \times 0 + 4 \times (-1) = 76 + 0 - 4 = 72\text{（分）}$$

答：$72$ 分。
