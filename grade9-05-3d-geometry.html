生活中的立體圖形：柱體、錐體與球體的表面積與體積

從平面幾何跨入 3D 立體空間！拆解角柱、圓柱、角錐、圓錐的平面展開圖，掌握「柱體體積 $=$ 底面積 $\times$ 高」、「錐體體積 $= \frac{1}{3} \times$ 底面積 $\times$ 高」與圓錐扇形側面積秒殺公式 $\pi r R$！

🎯 本單元核心學習目標

  • ✓熟記 $n$ 角柱與 $n$ 角錐的頂點數（$V$）、面數（$F$）、稜邊數（$E$）及歐拉公式 $V + F - E = 2$。
  • ✓掌握角柱與圓柱的表面積（$2\text{底} + \text{底周長}\times\text{高}$）與體積公式（$\text{底面積}\times\text{高}$）。
  • ✓精通圓錐展開圖關鍵關係：扇形弧長 $=$ 底圓周長，即 $\frac{\theta}{360^\circ} = \frac{r}{R}$，側面積 $= \pi r R$。
  • ✓認識錐體體積（$\frac{1}{3}\text{底面積}\times\text{高}$）、球體表面積 $4\pi r^2$ 與體積 $\frac{4}{3}\pi r^3$，以及空間最短路徑問題。

生活化比喻：吐司切片疊高（柱體體積）與壽司捲包裝紙（展開圖）

為什麼任何柱體的側面展開都是一個大長方形？為什麼圓錐展開扇形的角度只要看 $\frac{r}{R}$？

🍞 比喻一：柱體體積就是「一片吐司的底面積 $\times$ 疊起來的高度」

不管是三角柱、五角柱還是圓柱，都像把相同形狀的餅乾或吐司往上垂直疊高：

  • 體積通殺公式：$$\text{柱體體積} = \text{底面積} \times \text{柱高 } h$$
  • 側面包裝紙（側面積）：把洋芋片圓罐的側面包裝紙沿垂直線剪開攤平，它的長就是底面圓周長 $2\pi r$、寬就是柱高 $h$，所以柱體側面積永遠等於「底面周長 $\times$ 柱高」！

🎉 比喻二：派對尖帽（圓錐）展開圖的黃金比例 $\frac{r}{R}$

把底面半徑為 $r$、斜高（母線）為 $R$ 的圓錐派對帽剪開攤平，會得到一個扇形加一個底圓：

  • 因為扇形的圓弧原本剛好繞底圓一圈，所以扇形弧長 $=$ 底圓周長 $2\pi r$！
  • 由此推導出圓錐三大秒殺公式：
    1. 扇形佔全圓比例：$\frac{\theta}{360^\circ} = \frac{r}{R}$
    2. 圓錐側面積 $= \pi r R$
    3. 圓錐高 $h = \sqrt{R^2 - r^2}$（畢氏定理）

立體圖形頂點面稜邊與表面積、體積公式總表

柱體、錐體與球體必背公式一覽無遺

立體圖形 頂點 / 面 / 稜邊 或 展開圖特徵 表面積與體積核心公式
$n$ 角柱 • 頂點數：$2n$
• 面數：$n + 2$（$2$ 底面 $+$ $n$ 長方形側面）
• 稜邊數：$3n$ 		• $\text{表面積} = 2\times\text{底面積} + \text{底面周長}\times\text{高}$
• $\text{體積} = \text{底面積} \times \text{高}$
圓柱
(底半徑 $r$，高 $h$)		 側面展開為長 $2\pi r$、寬 $h$ 的長方形 • $\text{表面積} = 2\pi r^2 + 2\pi r h$
• $\text{體積} = \pi r^2 h$
$n$ 角錐 • 頂點數：$n + 1$
• 面數：$n + 1$（$1$ 底面 $+$ $n$ 三角形側面）
• 稜邊數：$2n$ 		• $\text{表面積} = \text{底面積} + \text{所有三角形側面面積和}$
• $\text{錐體體積} = \frac{1}{3} \times \text{底面積} \times \text{高}$
直圓錐
(底半徑 $r$，母線 $R$，高 $h$)		 側面展開為半徑 $R$ 的扇形，圓心角：$$\frac{\theta}{360^\circ} = \frac{r}{R}$$ • $\text{側面積} = \pi r R$，$\text{總表面積} = \pi r^2 + \pi r R$
• $\text{體積} = \frac{1}{3}\pi r^2 h \quad (h = \sqrt{R^2 - r^2})$
球體 (半徑 $r$) 空間中到球心距離等於 $r$ 的所有點；截面皆為圓 • $\text{球表面積} = 4\pi r^2$
• $\text{球體積} = \frac{4}{3}\pi r^3$

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「在圓錐公式中把扇形半徑（母線 $R$）與底圓半徑 $r$ 搞混」

算圓錐表面積時漏加底圓面積 $\pi r^2$，或把母線 $R$ 當成圓錐的垂直高 $h$。

✅ 正確觀念：母線 $R$ 是斜邊，底圓半徑 $r$ 與垂直高 $h$ 是兩股（$R^2 = r^2 + h^2$）；算總表面積務必記得 $\text{底圓 } \pi r^2 + \text{側面扇形 } \pi r R$！

❌ 錯誤迷思 2：「長方體表面螞蟻爬行最短距離，分開算兩段斜線相加」

沒有將立體表面攤平成平面就直接分段算。

✅ 正確觀念：立體表面最短路徑問題，一定要先把經過的兩個面「展開攤平在同一個平面上」，再用兩點間直線距離（畢氏定理）求解！

經典題型演練（點擊展開逐步詳解）

涵蓋圓柱體積與表面積、直圓錐展開圖與四角錐表面積計算

基礎題 圓柱的表面積與體積

1. 已知一個實心圓柱的底面圓半徑為 $5\text{ cm}$，柱高為 $10\text{ cm}$，求此圓柱的「總表面積」與「體積」分別為多少？

🔍 點擊展開逐步詳解▼

步驟 1：求總表面積（$2\text{底圓} + \text{長方形側面}$）

$$\text{表面積} = 2 \times (\pi \times 5^2) + (2\pi \times 5) \times 10 = 50\pi + 100\pi = 150\pi\text{ cm}^2$$

步驟 2：求體積（$\text{底面積} \times \text{高}$）

$$\text{體積} = (\pi \times 5^2) \times 10 = 250\pi\text{ cm}^3$$

答：總表面積為 $150\pi\text{ cm}^2$，體積為 $250\pi\text{ cm}^3$。

進階段考題 直圓錐展開圖圓心角與表面積

2. 將一個底面半徑 $r = 4\text{ cm}$、母線（斜高）$R = 12\text{ cm}$ 的直圓錐剪開攤平，求：(1) 側面扇形的圓心角為幾度？(2) 此直圓錐的總表面積為多少 $\text{cm}^2$？

🔍 點擊展開逐步詳解▼

步驟 1：利用黃金比例 $\frac{\theta}{360^\circ} = \frac{r}{R}$ 求扇形圓心角 $\theta$

$$\frac{\theta}{360^\circ} = \frac{4}{12} = \frac{1}{3} \implies \theta = 120^\circ$$

步驟 2：求總表面積 $= \pi r^2 + \pi r R$

$$\text{總表面積} = \pi(4^2) + \pi(4)(12) = 16\pi + 48\pi = 64\pi\text{ cm}^2$$

答：(1) $120^\circ$；(2) $64\pi\text{ cm}^2$。

會考素養題 正四角錐金字塔表面積計算

3. 有一座正四角錐模型，其底面為邊長 $10\text{ cm}$ 的正方形，四個側面皆為腰長 $13\text{ cm}$ 的等腰三角形。請問這座正四角錐模型的總表面積為多少 $\text{cm}^2$？

🔍 點擊展開逐步詳解▼

步驟 1：先算正方形底面積：$10 \times 10 = 100\text{ cm}^2$。

步驟 2：用畢氏定理求側面等腰三角形底邊上的高 $h_s$

底邊長 $10\text{ cm}$ 的一半為 $5\text{ cm}$，腰長為 $13\text{ cm}$，故側面三角形的高 $h_s = \sqrt{13^2 - 5^2} = 12\text{ cm}$。

步驟 3：計算四個側面三角形面積和並加總

$$\text{四個側面積} = 4 \times \left(\frac{1}{2} \times 10 \times 12\right) = 240\text{ cm}^2$$

$$\text{總表面積} = 100 + 240 = 340\text{ cm}^2$$

答：$340\text{ cm}^2$。
