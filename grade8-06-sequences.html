生活化比喻：爬樓梯跨步數與高斯倒序拼梯形

為什麼第 $10$ 項只加了 $9$ 個公差 $d$？為什麼等差級數公式長得跟梯形面積公式一模一樣？

🪜 比喻一：從 $1$ 樓走到 $n$ 樓，只需要爬 $(n-1)$ 層樓梯！

把首項 $a_1$ 當作 $1$ 樓的高度，每爬一層樓梯上升公差 $d$：

  • 從第 $1$ 項走到第 $10$ 項，中間只有 $10 - 1 = 9$ 個間隔，所以 $a_{10} = a_1 + 9d$！
  • 推廣：**任意第 $m$ 項走到第 $n$ 項，剛好相差 $(n - m)$ 個公差**：$$a_n = a_m + (n - m)d$$

📐 比喻二：等差級數求和就是「梯形面積公式：（上底＋下底）× 高 ÷ 2」

數學王子高斯小時候算 $1 + 2 + 3 + \dots + 100$：

  • 把首項 $a_1$ 當作上底、末項 $a_n$ 當作下底、總項數 $n$ 當作高。
  • 頭尾配對之和永遠相等（$1+100 = 2+99 = 101$），總和即為：$$S_n = \frac{(a_1 + a_n) \times n}{2}$$

核心公式表格與常見易錯提醒

等差數列、等差級數與等比數列公式完整對照

核心主題 標準數學公式 重要衍生性質與說明
等差數列第 $n$ 項 $$a_n = a_1 + (n - 1)d$$ $$d = \frac{a_n - a_m}{n - m}$$ 等差中項：若 $a, b, c$ 成等差，則 $b = \frac{a+c}{2}$。
等差級數前 $n$ 項和 $$S_n = \frac{n(a_1 + a_n)}{2} = \frac{n[2a_1 + (n - 1)d]}{2}$$ 當項數 $n$ 為奇數時，$S_n = n \times a_{\text{正中間項}}$。
等比數列第 $n$ 項 $$a_n = a_1 \times r^{n - 1} \quad (a_1, r \ne 0)$$ 等比數列中任何一項與公比 $r$ 皆不可為 $0$！
等比中項 若 $a, b, c$ 成等比，則 $b^2 = ac \implies b = \pm\sqrt{ac}$ 在等比數列中，同隔一項的兩數必同號！

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「$4$ 與 $9$ 的等比中項只有 $6$」

漏掉了公比 $r$ 可以是負數的情況（$4, -6, 9$ 公比為 $-\frac{3}{2}$）！

✅ 正確觀念：等比中項 $b = \pm\sqrt{4 \times 9} = \pm 6$，有正負兩解！

❌ 錯誤迷思 2：「在等比數列 $-2, x, -8$ 中，寫 $x = \pm 4$」

這卻是另一個反陷阱：若題目給的是等比數列連續幾項且有給正負號，要小心更遠的項有沒有固定符號！

✅ 正確觀念：若只給三項 $-2, x, -8$，則 $x = \pm 4$ 皆可；但若給五項 $-2, a, x, b, -32$，因為 $x = (-2) \cdot r^2$，而實數平方 $r^2 > 0$，此時 $x$ 必定只能是負數 $-8$！

經典題型演練（點擊展開逐步詳解）

涵蓋等差數列、等差級數座位總數與等比數列計算

基礎題 等差數列求公差與指定項

1. 一等差數列的第 $4$ 項為 $13$，第 $10$ 項為 $31$，求此數列的首項 $a_1$ 與第 $20$ 項 $a_{20}$。

🔍 點擊展開逐步詳解▼

步驟 1：先算公差 $d$：$d = \frac{a_{10} - a_4}{10 - 4} = \frac{31 - 13}{6} = 3$

步驟 2：求首項與第 $20$ 項

$a_1 = a_4 - 3d = 13 - 9 = 4$；$a_{20} = a_{10} + 10d = 31 + 30 = 61$。

答：$a_1 = 4, \; a_{20} = 61$。

進階段考題 等差級數最大值問題

2. 一等差級數首項為 $35$，公差為 $-4$，請問加到第幾項時，此等差級數的和 $S_n$ 會有最大值？最大值為多少？

🔍 點擊展開逐步詳解▼

步驟 1：把所有「正數項」全部加起來，總和就會最大！找出最後一個正數項：

$$a_n = 35 + (n - 1)(-4) > 0 \implies 39 - 4n > 0 \implies n < 9.75$$

故第 $9$ 項 $a_9 = 35 + 8(-4) = 3$ 是最後一個正數項。

步驟 2：計算前 $9$ 項總和 $S_9$

$$S_9 = \frac{9 \times (35 + 3)}{2} = 9 \times 19 = 171$$

答：加到第 $9$ 項時有最大值 $171$。

會考素養題 等比數列細菌倍增應用

3. 一等比數列的首項 $a_1 = 3$，第 $4$ 項 $a_4 = -24$，請問此等比數列的公比 $r$ 與第 $7$ 項 $a_7$ 分別為何？

🔍 點擊展開逐步詳解▼

步驟 1：由 $a_4 = a_1 \cdot r^3$ 求公比 $r$

$$-24 = 3 \cdot r^3 \implies r^3 = -8 \implies r = -2$$

步驟 2：求第 $7$ 項 $a_7$

$$a_7 = a_4 \cdot r^3 = (-24) \times (-8) = 192$$

答：公比 $r = -2$，第 $7$ 項 $a_7 = 192$。
