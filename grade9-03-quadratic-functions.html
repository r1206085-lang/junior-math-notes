九年級單元 03 • 課綱代碼：f-IV-2 • 學習內容：二次函數的圖形（頂點、對稱軸、開口方向與大小）、最大值與最小值應用

二次函數：拋物線頂點標準式與最大、最小值

從七年級的直線函數升級為優美的「拋物線」！掌握標準式 $y = a(x - h)^2 + k$，一眼讀出頂點 $(h, k)$、對稱軸 $x = h$ 與開口方向，解決籃球投籃最高點與商品定價最大利潤問題！

🎯 本單元核心學習目標

  • ✓理解首項係數 $a$ 決定開口方向（$a > 0$ 開口向上、$a < 0$ 開口向下）與開口大小（$|a|$ 越大開口越小）。
  • ✓熟練圖形平移口訣與頂點標準式 $y = a(x - h)^2 + k$（頂點為 $(h, k)$，對稱軸為 $x = h$）。
  • ✓能將一般式 $y = ax^2 + bx + c$ 用配方法化為頂點式，求出最大值或最小值 $k$。
  • ✓應用二次函數極值解決拋體運動高度、圍籬最大面積與票價調整最大營業額問題。
💡

生活化比喻：笑臉哭臉表情包與投籃拋物線軌跡

為什麼 $a > 0$ 有最小值、$a < 0$ 有最大值？為什麼往右平移 $3$ 單位括號內反而是 $(x - 3)^2$？

😊 比喻一：正能量笑臉（$a > 0$）vs. 負能量哭臉（$a < 0$）

二次項係數 $a$ 的正負號就是拋物線的心情：

  • $a > 0$（正能量 😊 嘴角上揚）：拋物線開口向上，頂點在最谷底，所以頂點是最低點（有最小值 $k$）！
  • $a < 0$（負能量 ☹️ 嘴角下垂）：像投籃飛出的籃球軌跡開口向下，頂點在最高峰，所以頂點是最高點（有最大值 $k$）！
  • 胖瘦看 $|a|$：$|a|$ 數字越大，拋物線越用力收緊，開口反而越窄越小！

🏀 比喻二：平方非負性秒懂頂點 $(h, k)$

為什麼 $y = 2(x - 3)^2 + 5$ 的最小值發生在 $x = 3$？

  • 因為任何實數的平方 $(x - 3)^2 \ge 0$，它最小最小就是變成 $0$！
  • 當我們令 $x = 3$ 時，平方向歸零，此時 $y$ 得到最小值 $0 + 5 = 5$。所以括號內令為 $0$ 的 $x = h$ 就是對稱軸，外面的 $+k$ 就是極值！
📘

核心公式表格與常見易錯提醒

頂點式、平移口訣、配方法與與兩軸交點個數判別

核心概念 數學公式與座標 關鍵性質與範例
頂點標準式 $$y = a(x - h)^2 + k \quad (a \ne 0)$$ • 頂點座標：$(h, k)$
• 對稱軸方程式：$x = h$
• 當 $x = h$ 時，有極值 $y = k$
拋物線平移法則 將 $y = ax^2$ 向右移 $h$、向上移 $k$：
$$y = a(x - h)^2 + k$$		 口訣：「左右平移括號內反號（左加右減），上下平移括號外同號（上加下減）」，且平移後 $a$ 絕不改變！
一般式轉頂點公式 $$y = ax^2 + bx + c$$ $$\text{頂點 } (h, k) = \left(-\frac{b}{2a}, \; \frac{4ac - b^2}{4a}\right)$$ 與 $y$ 軸交點必為 $(0, c)$；與 $x$ 軸交點個數由判別式 $b^2 - 4ac$（$>0$ 兩點、$=0$ 一點、$<0$ 無交點）決定。

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「$y = -2(x + 4)^2 - 7$ 的頂點是 $(4, -7)$」

忘記標準式中間是減號 $(x - h)^2$！

✅ 正確觀念：$(x + 4)^2 = [x - (-4)]^2$，令括號內 $x + 4 = 0$ 得 $x = -4$，故頂點是 $(-4, -7)$！

❌ 錯誤迷思 2：「配方法提出係數 $a$ 時，忘記在括號外平衡扣回 $a$ 倍！」

將 $y = -2(x^2 - 4x + 4) + 5$ 後面直接寫 $- 4$。

✅ 正確觀念：括號內的 $+4$ 乘上外面的 $-2$，實際上是減了 $8$，所以在括號外必須 $+8$ 才能保持等式不變！

✍️

經典題型演練（點擊展開逐步詳解）

涵蓋圖形平移、配方法求極值與定價最大營收應用題

基礎題 二次函數圖形平移與頂點

1. 將二次函數 $y = -3(x - 1)^2 + 4$ 的圖形向左平移 $3$ 個單位，再向下平移 $5$ 個單位，所得新二次函數的標準式、頂點座標與對稱軸分別為何？

🔍 點擊展開逐步詳解▼

步驟 1：直接移動原頂點 $(1, 4)$ 最快最不容易錯！

原頂點為 $(1, 4)$，向左移 $3$（$x$ 座標 $-3$）、向下移 $5$（$y$ 座標 $-5$）：

$$\text{新頂點} = (1 - 3, \; 4 - 5) = (-2, -1)$$

步驟 2：維持 $a = -3$ 不變，寫出新二次函數

$$y = -3(x + 2)^2 - 1$$

答：新函數為 $y = -3(x + 2)^2 - 1$，頂點 $(-2, -1)$，對稱軸 $x = -2$。

進階段考題 配方法求最大值或最小值

2. 求二次函數 $y = 2x^2 - 12x + 23$ 的頂點座標，並判斷此函數有最大值還是最小值？其值為何？

🔍 點擊展開逐步詳解▼

步驟 1：將前兩項提出二次項係數 $2$ 並進行配方

$$y = 2(x^2 - 6x) + 23$$

$$y = 2(x^2 - 6x + 3^2) + 23 - 2 \times 9$$

$$y = 2(x - 3)^2 + 5$$

步驟 2：判讀頂點與極值

頂點為 $(3, 5)$；因為 $a = 2 > 0$ 開口向上，當 $x = 3$ 時有最小值 $5$。

答：頂點 $(3, 5)$，有最小值 $5$。

會考素養題 價格調整與最大總收入問題

3. 某果園舉辦採草莓活動，若門票定價為每人 $200$ 元，平均每天有 $120$ 人入園；若門票每調漲 $10$ 元，每天入園人數就會減少 $4$ 人。請問門票定價為多少元時，果園每天的門票總收入會達到最大值？最大總收入為多少元？

🔍 點擊展開逐步詳解▼

步驟 1：設門票調漲 $x$ 次 $10$ 元，列出總收入函數 $y$

• 新票價 $= (200 + 10x)$ 元；新入園人數 $= (120 - 4x)$ 人

$$y = (200 + 10x)(120 - 4x)$$

步驟 2：利用兩根中點直接找出對稱軸 $h$（或展開配方）！

令兩括號為 $0$ 得 $x_1 = -20, \; x_2 = 30$，拋物線對稱軸必在兩交點正中間：

$$x = \frac{-20 + 30}{2} = 5$$

（亦可展開配方：$y = -40(x - 5)^2 + 25000$）

步驟 3：代回 $x = 5$ 求最佳票價與最大總收入

• 最佳定價 $= 200 + 10 \times 5 = 250$ 元

• 最大總收入 $= 250 \times (120 - 20) = 25000$ 元

答：定價 $250$ 元時，有最大總收入 $25000$ 元。
