幾何證明與三角形的三心：外心、內心、重心全制霸

從「已知 $\to$ 求證 $\to$ 證明」的嚴謹幾何推理（五大三角形全等性質 $SSS, SAS, ASA, AAS, RHS$），一路打通三角形最神奇的三個中心：外心 $O$、內心 $I$、重心 $G$！

🎯 本單元核心學習目標

  • ✓熟練三角形五大全等性質（$SSS, SAS, ASA, AAS, RHS$）、中垂線性質與角平分線性質。
  • ✓理解外心 $O$（三邊中垂線交點）：到三頂點等距，且直角三角形外心在斜邊中點（$R = \frac{c}{2}$）。
  • ✓理解內心 $I$（三內角平分線交點）：到三邊等距，面積 $\triangle ABC = \frac{1}{2} r s$，直角三角形 $r = \frac{a+b-c}{2}$。
  • ✓理解重心 $G$（三中線交點）：重心到頂點與到底邊中點比為 $2 : 1$，三中線將三角形面積六等分。

生活化比喻：三心選址大作戰（基地台、噴水池與平衡手指）

外心、內心、重心到底差在哪裡？用三個生活選址任務一次記住一輩子！

📡 外心 $O$：距離三個村莊（頂點）一樣遠的基地台

要在 $A, B, C$ 三個村莊蓋一座訊號塔，使到三頂點距離相等（$\overline{OA}=\overline{OB}=\overline{OC}=R$），就要找三邊中垂線交點（外接圓圓心）！

⛲ 內心 $I$：距離三條馬路（三邊）一樣近的圓形噴水池

在三條道路圍成的三角公園內蓋最大的圓形噴水池，使到三邊垂直距離相等（$= r$），就要找三內角平分線交點（內切圓圓心）！

☝️ 重心 $G$：一根手指頭頂住三角形厚紙板的平衡點

把三角形切塊面積平分的三條中線交點就是重量中心！手指頂在 $G$ 點紙板不會掉下來，且每塊小三角形面積完全相等（六等分）！

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「SSA 也是三角形全等性質！」

已知兩邊與一「非夾角」相等，誤以為兩三角形必全等。

✅ 正確觀念：沒有 SSA 全等，也沒有 AAA 全等！除非那個非夾角剛好是 $90^\circ$ 直角，才會構成 $RHS$（斜邊與一股）全等。

❌ 錯誤迷思 2：「外心一定在三角形內部，且 $\angle BOC$ 永遠等於 $2\angle A$」

忽略了鈍角三角形的外心在三角形外部！

✅ 正確觀念：鈍角三角形外心在外部，當 $\angle A > 90^\circ$ 時，$\angle BOC = 360^\circ - 2\angle A$。

經典題型演練（點擊展開逐步詳解）

精選直角三角形三心綜合題、內心角度與重心面積比例題

基礎題 內心角度公式與外心角度公式

1. 在銳角 $\triangle ABC$ 中，$\angle A = 70^\circ$。若 $O$ 為 $\triangle ABC$ 的外心，$I$ 為 $\triangle ABC$ 的內心，求 $\angle BOC$ 與 $\angle BIC$ 的度數分別為何？

🔍 點擊展開逐步詳解▼

步驟 1：求外心夾角 $\angle BOC$（銳角三角形）

$$\angle BOC = 2\angle A = 2 \times 70^\circ = 140^\circ$$

步驟 2：求內心夾角 $\angle BIC$

$$\angle BIC = 90^\circ + \frac{1}{2}\angle A = 90^\circ + 35^\circ = 125^\circ$$

答：$\angle BOC = 140^\circ$，$\angle BIC = 125^\circ$。

進階段考題 直角三角形外接圓半徑、內切圓半徑與三心距離

2. 已知直角 $\triangle ABC$ 中，$\angle C = 90^\circ$，兩股長 $\overline{AC} = 6$、$\overline{BC} = 8$。求：(1) 外接圓半徑 $R$；(2) 內切圓半徑 $r$；(3) 重心 $G$ 到外心 $O$ 的距離 $\overline{GO}$。

🔍 點擊展開逐步詳解▼

步驟 1：由畢氏定理得斜邊 $\overline{AB} = \sqrt{6^2 + 8^2} = 10$

步驟 2：套用直角三角形三心黃金公式

• (1) 外接圓半徑 $R = \frac{\text{斜邊}}{2} = \frac{10}{2} = 5$

• (2) 內切圓半徑 $r = \frac{6 + 8 - 10}{2} = 2$

• (3) 斜邊中線長即 $R = 5$，重心分中線為 $2 : 1$，故 $\overline{GO} = \frac{1}{3} \times 5 = \frac{5}{3}$。

答：(1) $R = 5$；(2) $r = 2$；(3) $\overline{GO} = \frac{5}{3}$。

會考素養題 重心六等分面積與比例性質

3. 在 $\triangle ABC$ 中，三條中線 $\overline{AD}$、$\overline{BE}$、$\overline{CF}$ 相交於重心 $G$。若 $\overline{GD} = 4\text{ cm}$，且四邊形 $BDGF$ 的面積為 $18\text{ cm}^2$，求中線 $\overline{AD}$ 的全長與 $\triangle ABC$ 的總面積。

🔍 點擊展開逐步詳解▼

步驟 1：利用重心長度比 $\overline{AG} : \overline{GD} = 2 : 1$ 求 $\overline{AD}$

$\overline{AG} = 2 \times 4 = 8\text{ cm}$，故全長 $\overline{AD} = 8 + 4 = 12\text{ cm}$。

步驟 2：利用三條中線將 $\triangle ABC$ 面積平分為 $6$ 塊相等的小三角形

四邊形 $BDGF$ 是由 $2$ 塊小三角形（$\triangle BDG$ 與 $\triangle BFG$）組成，佔總面積的 $\frac{2}{6} = \frac{1}{3}$。

故 $\triangle ABC$ 總面積 $= 18 \times 3 = 54\text{ cm}^2$。

答：$\overline{AD} = 12\text{ cm}$，$\triangle ABC$ 面積為 $54\text{ cm}^2$。
