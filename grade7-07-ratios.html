比與比例式：黃金比例調配與正反比關係

掌握「外項乘積 $=$ 內項乘積」與參數設法 $x = ar, y = br$，並釐清生活中哪些數量是「同倍數成長的正比」、哪些是「乘積固定的反比」！

🎯 本單元核心學習目標

  • ✓理解比 $a : b$ 與比值 $\frac{a}{b}$（$b \ne 0$），並熟練比例式性質：$a : b = c : d \iff ad = bc$。
  • ✓學會利用比例參數法：若 $x : y = 3 : 5$，可設 $x = 3r, \; y = 5r$（$r \ne 0$）代入求解。
  • ✓理解正比定義：$y = kx$（即比值 $\frac{y}{x} = k$ 為定值）。
  • ✓理解反比定義：$xy = k$（即兩數乘積為定值，當 $x$ 變 $2$ 倍，$y$ 變 $\frac{1}{2}$ 倍）。

生活化比喻：手搖飲黃金比例配方與切蛋糕分食

為什麼「變大」不一定就是正比？怎麼一秒區分正比與反比？

🧋 比喻一：手搖飲調配與正比（單價固定時，買越多杯越貴）

一杯紅茶拿鐵的「紅茶 : 鮮奶 $= 3 : 2$」：

  • 不論小杯或特大杯，只要比值 $\frac{\text{紅茶}}{\text{鮮奶}} = \frac{3}{2}$ 固定不變，喝起來甜度口感就完全一樣！我們可以設紅茶為 $3r\text{ ml}$、鮮奶為 $2r\text{ ml}$。
  • 這就是正比（$\frac{y}{x} = k$）：當鮮奶量變 $3$ 倍，紅茶量也必須變 $3$ 倍！

🎂 比喻二：反比就像「同一個大披薩分給越多人，每人吃越少」

一個 $1200$ 公克的披薩平分給 $x$ 人，每人分到 $y$ 公克：

  • 總重量（乘積）永遠固定：$$\text{人數 } x \times \text{每人克數 } y = 1200$$
  • 當人數 $x$ 變成 $2$ 倍時，每人分到的重量 $y$ 就會縮小成 $\frac{1}{2}$ 倍，這才是真正的反比（$xy = k$）！

核心公式表格與常見易錯提醒

比例式三大性質與正比、反比判定表

核心概念 數學公式與代數技巧 生活實例與應用
比例式基本性質 $$a : b = c : d \iff ad = bc$$（外項乘積 $=$ 內項乘積） 反之，若題目給 $3x = 7y$，要小心還原成比例式時是 $x : y = 7 : 3$！
參數假設法 若 $x : y = a : b$，則設 $x = ar, \; y = br \quad (r \ne 0)$ 代入含 $x, y$ 的方程式求出 $r$，即可同時算出 $x$ 與 $y$。
正比 ($y$ 與 $x$ 成正比) $$y = kx \quad \text{或} \quad \frac{y}{x} = k \quad (k \ne 0)$$ 例：速率固定時，距離與時間成正比；圓周長 $2\pi r$ 與半徑 $r$ 成正比。
反比 ($y$ 與 $x$ 成反比) $$x \cdot y = k \quad (k \ne 0)$$ 例：距離固定時，速率與時間成反比；長方形面積固定時，長與寬成反比。

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「看到 $4x = 9y$，就寫 $x : y = 4 : 9$」

直接照抄係數順序，違反了內項積等於外項積！

✅ 正確觀念：若 $4x = 9y$，則 $x : y = 9 : 4$（檢驗內項積 $9y$ 等於外項積 $4x$ 才正確）！

❌ 錯誤迷思 2：「一天 24 小時中，白天長度 $x$ 與夜晚長度 $y$ 成反比」

誤以為「一個變大、另一個變小」就是成反比。

✅ 正確觀念：白天 $+$ 夜晚 $= x + y = 24$ 是和固定，不是乘積 $xy$ 固定，所以既不成正比也不成反比！

✍️

經典題型演練（點擊展開逐步詳解）

涵蓋內外項乘積、參數法與正反比關係計算

基礎題 比例式參數假設法

1. 已知 $(2x + y) : (x - y) = 5 : 1$，且 $x + 2y = 14$，求 $x$ 與 $y$ 的值。

🔍 點擊展開逐步詳解▼

步驟 1：利用「內項乘積 $=$ 外項乘積」化簡比例式

$$5(x - y) = 1(2x + y) \implies 5x - 5y = 2x + y \implies 3x = 6y \implies x : y = 2 : 1$$

步驟 2：設 $x = 2r, \; y = r$（$r \ne 0$）代入 $x + 2y = 14$

$$2r + 2r = 14 \implies 4r = 14 \implies r = \frac{7}{2}$$

故 $x = 2 \times \frac{7}{2} = 7$，$y = \frac{7}{2}$。

答：$x = 7, \; y = \frac{7}{2}$。

進階段考題 正比與反比函數關係式

2. 已知 $(y + 2)$ 與 $(x - 1)$ 成反比，且當 $x = 5$ 時，$y = 4$。請問當 $x = -3$ 時，$y$ 的值為何？

🔍 點擊展開逐步詳解▼

步驟 1：依反比定義（乘積為定值 $k$）列關係式

$$(x - 1)(y + 2) = k$$

步驟 2：將 $x = 5, \; y = 4$ 代入求出常數 $k$

$$(5 - 1)(4 + 2) = k \implies k = 4 \times 6 = 24$$

步驟 3：代回關係式 $(x - 1)(y + 2) = 24$，令 $x = -3$ 求 $y$

$$(-3 - 1)(y + 2) = 24 \implies -4(y + 2) = 24 \implies y + 2 = -6 \implies y = -8$$

答：$y = -8$。

會考素養題 齒輪轉動齒數與圈數反比問題

3. 機械鐘錶內有甲、乙兩個互相咬合的齒輪，已知甲齒輪有 $48$ 齒，乙齒輪有 $32$ 齒。當甲齒輪轉動 $12$ 圈時，乙齒輪會轉動幾圈？

🔍 點擊展開逐步詳解▼

步驟 1：理解咬合齒輪的物理規律（轉過總齒數相等，故齒數與圈數成反比）

$$\text{甲齒數} \times \text{甲圈數} = \text{乙齒數} \times \text{乙圈數}$$

步驟 2：代入數值求解

$$48 \times 12 = 32 \times \text{乙圈數} \implies \text{乙圈數} = \frac{576}{32} = 18$$

答：乙齒輪會轉動 $18$ 圈。
