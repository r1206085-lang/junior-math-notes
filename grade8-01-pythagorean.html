畢氏定理（勾股定理）：直角三角形的三邊密碼

連結代數平方根與幾何圖形的橋樑！探索直角三角形兩股平方和等於斜邊平方的永恆定律，並解決消防雲梯、電視螢幕尺寸與坐標平面距離問題。

🎯 本單元核心學習目標

  • ✓ 透過正方形面積拼貼直觀理解畢氏定理：$a^2 + b^2 = c^2$。
  • ✓ 已知直角三角形任意兩邊長，能快速求出第三邊長，並熟記常見畢氏數。
  • ✓ 理解並計算直角三角形「斜邊上的高」公式 $h = \frac{ab}{c}$。
  • ✓ 應用畢氏定理求直角坐標平面上任意兩點 $A(x_1, y_1)$ 與 $B(x_2, y_2)$ 的直線距離。

生活化比喻：公園切西瓜走捷徑與地板方格磁磚

為什麼走對角線比較快？畢達哥拉斯在朋友家的地板磁磚看到了什麼？

🧱 比喻一：地板上的三塊正方形磁磚拼圖

古希臘數學家畢達哥拉斯造訪朋友家時，盯著地板上的直角三角形與周圍的正方形磁磚發現：

  • 在兩條較短的直角邊（稱為股，長 $3$ 與 $4$）向外鋪正方形，分別需要 $3^2 = 9$ 塊與 $4^2 = 16$ 塊小磁磚。
  • 在最長邊（直角對面的斜邊，長 $5$）向外鋪正方形，剛好需要 $5^2 = 25$ 塊小磁磚！
  • 驚人巧合：兩小正方形面積總和 $=$ 最大正方形面積（$9 + 16 = 25$）！

🏃 比喻二：長方形公園「走對角線捷徑」省幾公尺？

假設長方形公園的邊長分別是往東 $60$ 公尺、往北 $80$ 公尺：

  • 如果乖乖沿著外圍人行道轉彎走，總共要走 $60 + 80 = 140$ 公尺。
  • 如果直接穿越對角線步道（斜邊 $c$），根據畢氏定理： $$c = \sqrt{60^2 + 80^2} = \sqrt{3600 + 6400} = \sqrt{10000} = 100 \text{ 公尺}$$
  • 走對角線足足省下了 $140 - 100 = 40$ 公尺！電視機標示的「65 吋螢幕」也是量這條斜邊對角線喔！

核心公式表格與常見易錯提醒

從三邊長關係、斜邊上的高到直角坐標平面兩點距離公式

核心概念 數學公式與代數變形 適用條件與說明
畢氏定理本尊 $$\text{兩股平方和} = \text{斜邊平方}$$ $$a^2 + b^2 = c^2$$ 僅適用於直角三角形，其中 $c$ 必為直角（$90^\circ$）所對的最長邊（斜邊）。
求斜邊 vs. 求股 求斜邊：$c = \sqrt{a^2 + b^2}$
求一股：$a = \sqrt{c^2 - b^2}$ 		求一股時可用平方差公式加速計算：
$$\sqrt{25^2 - 24^2} = \sqrt{(25+24)(25-24)} = \sqrt{49} = 7$$
斜邊上的高 $$h = \frac{\text{兩股相乘}}{\text{斜邊}} = \frac{a \times b}{c}$$ 由同一個直角三角形面積相等推導而來：
$$\frac{1}{2}ab = \frac{1}{2}ch \implies ab = ch$$
特殊直角三角形 等腰直角（$45^\circ\text{-}45^\circ\text{-}90^\circ$）：$1 : 1 : \sqrt{2}$
半正三角形（$30^\circ\text{-}60^\circ\text{-}90^\circ$）：$1 : \sqrt{3} : 2$ 		邊長為 $a$ 的正三角形：高 $h = \frac{\sqrt{3}}{2}a$，面積 $= \frac{\sqrt{3}}{4}a^2$。
坐標平面兩點距離 $$\overline{AB} = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$ 水平距離 $|x_1 - x_2|$ 與鉛直距離 $|y_1 - y_2|$ 構成直角三角形的兩股。

⚠️ 常見易錯觀念提醒（段考陷阱正誤對照）

❌ 錯誤迷思 1：「看到 $3$ 和 $4$，第三邊就無腦填 $5$！」

題目只說「直角三角形兩邊長為 $3$ 和 $4$」，未指明 $4$ 是股還是斜邊。

✅ 正確觀念：若 $3, 4$ 為兩股，則斜邊為 $5$；但若$4$ 是斜邊，則另一股為 $\sqrt{4^2 - 3^2} = \sqrt{7}$！有兩解！

❌ 錯誤迷思 2：「$\sqrt{a^2 + b^2} = a + b$」

誤把根號內的加法直接分別開根號，例如以為 $\sqrt{3^2 + 4^2} = 3 + 4 = 7$。

✅ 正確觀念：根號內有加減號時，必須先算出平方和的總數才能開根號：$\sqrt{9 + 16} = \sqrt{25} = 5 \ne 7$。

經典題型演練（點擊展開逐步詳解）

涵蓋斜邊高、雲梯滑動應用題與坐標平面距離計算

基礎題 畢氏定理與斜邊上的高

1. 已知直角三角形 $ABC$ 中，$\angle C = 90^\circ$，兩股長分別為 $\overline{AC} = 5$、$\overline{BC} = 12$。求：(1) 斜邊 $\overline{AB}$ 的長；(2) 斜邊上的高 $\overline{CD}$ 的長。

🔍 點擊展開逐步詳解 ▼

步驟 1：利用畢氏定理求斜邊 $\overline{AB}$

$$\overline{AB} = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13$$

（或直接由黃金畢氏數 $(5, 12, 13)$ 秒答！）

步驟 2：利用面積相等求斜邊上的高 $\overline{CD}$

$$\overline{CD} = \frac{\text{兩股相乘}}{\text{斜邊}} = \frac{5 \times 12}{13} = \frac{60}{13}$$

答：(1) $\overline{AB} = 13$；(2) $\overline{CD} = \frac{60}{13}$。

進階段考題 鋁梯靠牆滑動問題

2. 有一架長 $25$ 公尺的消防雲梯斜靠在一座垂直的牆壁上，原本梯腳距離牆角 $7$ 公尺。若雲梯頂端沿著牆壁下滑了 $4$ 公尺，請問此時梯腳會往外滑移多少公尺？

🔍 點擊展開逐步詳解 ▼

步驟 1：抓住核心關鍵——「雲梯本身的長度（斜邊 $25$ 公尺）永遠不變」！

先求原本梯頂離地面的高度 $h_1$：

$$h_1 = \sqrt{25^2 - 7^2} = \sqrt{625 - 49} = \sqrt{576} = 24 \text{ 公尺}$$

步驟 2：計算梯頂下滑 $4$ 公尺後的新高度 $h_2$

$$h_2 = 24 - 4 = 20 \text{ 公尺}$$

步驟 3：求滑動後梯腳距離牆角的新距離 $d_2$

$$d_2 = \sqrt{25^2 - 20^2} = \sqrt{625 - 400} = \sqrt{225} = 15 \text{ 公尺}$$

步驟 4：求梯腳往外滑移的距離（切勿誤以為頂端下滑 $4$ 公尺，底部也滑移 $4$ 公尺！）

$$\text{滑移距離} = 15 - 7 = 8 \text{ 公尺}$$

答：梯腳會往外滑移 $8$ 公尺。

會考素養題 直角坐標平面上的兩點距離

3. 在直角坐標平面上，若學校位於點 $A(-2, 3)$，圖書館位於點 $B(6, -3)$，且每單位長代表 $100$ 公尺。請問學校到圖書館的直線距離是多少公尺？

🔍 點擊展開逐步詳解 ▼

步驟 1：分別計算水平距離（$\Delta x$）與鉛直距離（$\Delta y$）

$$\Delta x = |6 - (-2)| = 8 \text{ 單位}$$

$$\Delta y = |-3 - 3| = 6 \text{ 單位}$$

步驟 2：套用兩點距離公式（畢氏定理）

$$\overline{AB} = \sqrt{8^2 + 6^2} = \sqrt{64 + 36} = \sqrt{100} = 10 \text{ 單位長}$$

步驟 3：換算為實際公尺數

$$10 \times 100 = 1000 \text{ 公尺}$$

答：直線距離為 $1000$ 公尺（或 $1$ 公里）。
