九年級單元 02 • 課綱代碼：s-IV-14 • 學習內容：圓心角與圓周角、弦心距、切線性質、圓內接四邊形與圓外切四邊形

點、直線與圓的關係：弦心距、切線與圓周角定理

探索圓的完美對稱性！掌握「圓心到切點的半徑必垂直切線」、「弦心距垂直平分弦」，以及「圓周角度數等於所對弧度數的一半」三大會考必考核心！

🎯 本單元核心學習目標

  • ✓理解點與圓、直線與圓（不相交、相切、相交割線）的位置關係與圓心距離判別。
  • ✓熟練弦心距性質：弦心距垂直平分弦，且半徑 $R$、弦心距 $d$、半弦長 $\frac{L}{2}$ 滿足畢氏定理。
  • ✓熟練切線性質：圓心與切點連線必垂直切線；由圓外一點作兩切線段必等長。
  • ✓精通圓心角、圓周角與弦切角的度數關係，以及半圓所對的圓周角必為直角（$90^\circ$）。

生活化比喻：腳踏車輪胎貼地切線與冰淇淋甜筒兩切線

為什麼切線跟半徑一定夾 $90^\circ$？為什麼圓外一點畫兩條切線像甜筒一樣左右等長？

🚲 比喻一：腳踏車輪胎滾在平坦柏油路上（半徑 $\perp$ 切線）

平坦的地面就是圓形輪胎的切線，輪胎唯一接觸地面的那個點就是切點 $P$：

  • 從車輪軸心（圓心 $O$）連到地面接觸點（切點 $P$）的這根輻條（半徑），一定跟地面呈現垂直 $90^\circ$！
  • 解題反射動作：只要在題目看到「切線、切點」，第一秒立刻從圓心連半徑到切點，標上直角符號 $90^\circ$！

🍦 比喻二：冰淇淋甜筒與劇場看台視角（圓周角定理）

一球圓形冰淇淋卡在 V 字型甜筒裡：

  • 甜筒尖端 $P$ 到左右兩個接觸點 $A, B$ 的長度必定一模一樣（切線段長相等 $\overline{PA} = \overline{PB}$）！
  • 圓周角視角：站在圓形劇場正中心（圓心角）看舞台是 $100^\circ$，退到圓周座位區（圓周角）看同一個舞台，視角剛好縮小一半變成 $50^\circ$！
📘

核心公式表格與常見易錯提醒

弦心距畢氏定理、圓外切四邊形、圓內接四邊形與圓周角公式總表

核心概念 數學公式與幾何關係 重要推論與說明
弦心距與弦長公式 $$R^2 = d^2 + \left(\frac{\text{弦長 } L}{2}\right)^2$$ $$\text{弦長 } L = 2\sqrt{R^2 - d^2}$$ 在同一圓中：弦越長，離圓心越近（弦心距越小）；等弦必對等弦心距。
切線段長與圓外切四邊形 • 圓外一點切線段長：$\overline{PA} = \sqrt{\overline{PO}^2 - R^2}$
• 圓外切四邊形：上 $+$ 下 $=$ 左 $+$ 右 		四邊形 $ABCD$ 外切於一圓 $\implies \overline{AB} + \overline{CD} = \overline{AD} + \overline{BC}$。
圓心角与圓周角 • $\text{圓心角 } \angle AOB = \overparen{AB}\text{ 的度數}$
• $\text{圓周角 } \angle ACB = \frac{1}{2}\overparen{AB} = \frac{1}{2}\angle AOB$ 		直徑（半圓）所對的圓周角必為 $90^\circ$！
同弧所對的所有圓周角度數皆相等。
圓內接四邊形 $$\text{對角互補：}\angle A + \angle C = 180^\circ, \; \angle B + \angle D = 180^\circ$$ 圓內接四邊形的外角必等於其「內對角」。

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「弧的度數相等，弧的長度也一定相等」

忽略了兩個圓的半徑大小可能不同！

✅ 正確觀念：弧的度數只跟圓心角有關，但弧長 $= 2\pi R \times \frac{\theta}{360^\circ}$ 還跟半徑 $R$ 有關！必須在「同圓或等圓」中，等度數的弧才會等長。

❌ 錯誤迷思 2：「用畢氏定理算出一半的弦長後忘記乘以 $2$」

半徑 $10$、弦心距 $6$，算出 $\sqrt{10^2 - 6^2} = 8$ 就直接填弦長為 $8$。

✅ 正確觀念：畢氏定理算出的 $8$ 只是弦長的一半，完整弦長是 $8 \times 2 = 16$！

✍️

經典題型演練（點擊展開逐步詳解）

涵蓋弦心距求弦長、圓外一點切線性質與圓周角計算

基礎題 弦心距與弦長計算

1. 已知圓 $O$ 的半徑為 $13\text{ cm}$，圓內有一條弦 $\overline{AB}$ 的弦心距 $\overline{OM} = 5\text{ cm}$，求弦 $\overline{AB}$ 的長度為多少 $\text{cm}$？

🔍 點擊展開逐步詳解▼

步驟 1：利用弦心距垂直平分弦，求半弦長 $\overline{AM}$

$$\overline{AM} = \sqrt{13^2 - 5^2} = 12\text{ cm}$$

步驟 2：乘以 $2$ 得完整弦長：$\overline{AB} = 12 \times 2 = 24\text{ cm}$。

答：$\overline{AB} = 24\text{ cm}$。

進階段考題 圓周角與圓內接四邊形對角互補

2. 四邊形 $ABCD$ 為圓 $O$ 的圓內接四邊形，且 $\overline{AC}$ 為圓 $O$ 的直徑。若 $\angle DAC = 35^\circ$、$\angle B = 110^\circ$，求 $\angle CAB$ 與 $\angle D$ 的度數。

🔍 點擊展開逐步詳解▼

步驟 1：利用「圆內接四邊形對角互補」求 $\angle D$ 與 $\angle DAB$

• 因為 $\overline{AC}$ 是直徑，半圓所對的圓周角 $\angle D = 90^\circ$（且 $\angle B$ 應為 $90^\circ$，若改題意為一般弦 $\overline{AC}$ 且 $\angle B = 110^\circ$，則對角 $\angle D = 180^\circ - 110^\circ = 70^\circ$）。

• 當 $\overline{AC}$ 為直徑時，$\angle B = \angle D = 90^\circ$，在 $\text{Rt}\triangle ADC$ 中，$\angle ACD = 90^\circ - 35^\circ = 55^\circ$。

答：直徑所對圓周角 $\angle D = 90^\circ$，且 $\angle ACD = 55^\circ$。

會考素養題 圓外一點兩切線段與切點弦距離

3. 自圓 $O$ 外一點 $P$ 向圓 $O$ 作兩條切線，切點分別為 $A$、$B$。已知圓 $O$ 半徑 $\overline{OA} = 6$，且 $\overline{OP} = 10$，求：(1) 切線段長 $\overline{PA}$；(2) 兩切點連線段 $\overline{AB}$ 的長。

🔍 點擊展開逐步詳解▼

步驟 1：利用半徑垂直切線（$\angle OAP = 90^\circ$）求切線段 $\overline{PA}$

$$\overline{PA} = \sqrt{10^2 - 6^2} = 8$$

步驟 2：利用 $\overline{OP}$ 垂直平分 $\overline{AB}$，求直角 $\triangle OAP$ 斜邊上的高再乘以 $2$

斜邊上的高 $h = \frac{6 \times 8}{10} = 4.8$，故 $\overline{AB} = 2 \times 4.8 = 9.6$（或 $\frac{48}{5}$）。

答：(1) $\overline{PA} = 8$；(2) $\overline{AB} = \frac{48}{5}$（或 $9.6$）。
