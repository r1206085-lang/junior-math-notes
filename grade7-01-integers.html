正負數與絕對值：數線上的方向與距離

從國小熟悉的「0 與正數」擴展到「負數世界」，透過數線理解相反數的對稱美感，並掌握絕對值代表「距離永不為負」的核心概念。

🎯 本單元核心學習目標

  • ✓ 能以「基準點 $0$」與「相對方向」理解正數（$+$）與負數（$-$）在生活中的意義。
  • ✓ 認識數線三要素（原點、正向、單位長），並在數線上標示正負數與比較大小。
  • ✓ 理解相反數的幾何與代數意義：兩數互為相反數 $\iff a + b = 0$。
  • ✓ 掌握絕對值 $|a|$ 的本質為「數線上點到原點的距離」，理解 $|a| \ge 0$ 的非負性質。

生活化比喻：百貨公司電梯樓層與計步器

為什麼負數越大反而越小？為什麼絕對值出來一定不是負數？

🏢 比喻一：百貨公司 1 樓大廳 vs. 地下停車場

想像百貨公司的地面大廳是原點 $0$：

  • 往上坐電梯到 地上 3 樓，記為 $+3$。
  • 往下坐電梯到 地下 3 樓（B3），記為 $-3$。
  • 比大小直覺：地下 5 樓（$-5$）比地下 2 樓（$-2$）還要深、還要低，所以在數線上： $$-5 < -2 < 0 < +3$$

👣 比喻二：絕對值就是「計步器上的步數」

假設你站在家門口（原點 $0$），往東走記為 $+$，往西走記為 $-$：

  • 往東走 $5$ 步到達 $+5$，你離家門口的距離是 $|+5| = 5$ 步。
  • 往西走 $5$ 步到達 $-5$，雖然方向相反，但計步器紀錄的步數（距離）一樣是 $|-5| = 5$ 步！
  • 這就是為什麼絕對值代表距離，永遠大於或等於 $0$（計步器不可能走出負的步數）。

數線對稱與絕對值距離示意圖

← 往左越小 (負向) |-3| = 3 單位長 ⟷ |+3| = 3 單位長 往右越大 (正向) →
-3 -2 -1 0 (原點) +1 +2 +3

核心公式表格與常見易錯提醒

段考與會考必備的數線、相反數與絕對值定義總整理

核心概念 數學公式與代數定義 幾何意義與實例
數線三要素 原點（$0$）、正向（通常向右）、單位長（$1$） 數線上右邊的數必大於左邊的數：若 $A$ 在 $B$ 右側，則 $a > b$。
相反數 數 $a$ 的相反數為 $-a$，且滿足：
$$a + (-a) = 0$$ 		在數線上分別位於原點兩側，且到原點距離相等。
例：$5$ 的相反數是 $-5$；$0$ 的相反數是 $0$。
絕對值定義 $$|a| = \begin{cases} a, & \text{當 } a > 0 \\ 0, & \text{當 } a = 0 \\ -a, & \text{當 } a < 0 \end{cases}$$ $|a|$ 代表點 $A(a)$ 到原點 $O(0)$ 的距離。
例：$|7| = 7$，$|-7| = -(-7) = 7$。
兩點間距離 數線上 $A(a)$ 與 $B(b)$ 兩點的距離：
$$\overline{AB} = |a - b| = |b - a|$$ 		大數減小數，或直接相減取絕對值。
例：$-4$ 與 $3$ 的距離 $= |3 - (-4)| = 7$。
絕對值非負性 對任意數 $a, b$，恆有 $|a| \ge 0$。
若 $|a| + |b| = 0$，則必有 $a = 0$ 且 $b = 0$。 		兩個「不小於 $0$ 的距離」相加等於 $0$，唯一可能是兩個距離本身都是 $0$！

⚠️ 常見易錯觀念提醒（段考陷阱正誤對照）

❌ 錯誤迷思 1：「負數比較大小時，數字越大就越大」

誤以為 $-8 > -3$（因為 $8 > 3$）。

✅ 正確觀念：負數代表往左走，負號後面的數字（絕對值）越大，位置越左邊，值反而越小！因此 $-8 < -3$。

❌ 錯誤迷思 2：「若 $|x| = 5$，則 $x = 5$」

漏掉了左邊負方向的對稱點！

✅ 正確觀念：到原點距離為 $5$ 的點有左右兩個，故 $|x| = 5 \implies x = 5 \text{ 或 } -5$（記為 $\pm 5$）。

基礎題 絕對值與四則運算

1. 計算下列各式的值：$$|-12| - |5 - 13| + |-7|$$

🔍 點擊展開逐步詳解 ▼

步驟 1：先算各絕對值符號內部的運算

$$|-12| = 12$$

$$|5 - 13| = |-8| = 8$$

$$|-7| = 7$$

步驟 2：代回原式進行加減

$$\text{原式} = 12 - 8 + 7 = 4 + 7 = 11$$

答：$11$

進階段考題 絕對值非負性質應用

2. 已知 $a$、$b$ 為整數，且滿足 $|a - 4| + |b + 6| = 0$，求 $a + b$ 的值為何？

🔍 點擊展開逐步詳解 ▼

步驟 1：利用絕對值的非負性（距離必 $\ge 0$）

因為 $|a - 4| \ge 0$ 且 $|b + 6| \ge 0$，兩個非負數相加要等於 $0$，唯一可能是兩項都為 $0$。

步驟 2：分別列式求解 $a, b$

$$a - 4 = 0 \implies a = 4$$

$$b + 6 = 0 \implies b = -6$$

步驟 3：計算所求 $a + b$

$$a + b = 4 + (-6) = -2$$

答：$-2$

會考素養題 數線距離與整數點個數

3. 在數線上，若整數 $x$ 滿足 $|x| < 4.3$，則符合條件的整數 $x$ 共有幾個？把它們全部加起來的總和是多少？

🔍 點擊展開逐步詳解 ▼

步驟 1：翻譯絕對值不等式的幾何意義

$|x| < 4.3$ 代表「數線上點 $x$ 到原點 $0$ 的距離小於 $4.3$」。

步驟 2：列出所有符合的整數點（別忘了 $0$！）

正整數有：$1, 2, 3, 4$（共 $4$ 個）

負整數有：$-1, -2, -3, -4$（共 $4$ 個）

原點：$0$（共 $1$ 個）

總個數 $= 4 + 4 + 1 = 9$ 個。

步驟 3：利用相反數成對抵銷求總和

$$(-4+4) + (-3+3) + (-2+2) + (-1+1) + 0 = 0$$

答：共有 $9$ 個整數，總和為 $0$。
