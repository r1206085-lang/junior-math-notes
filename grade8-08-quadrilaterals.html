平行與四邊形：截角定律與四邊形家族族譜

掌握兩平行線被截線所截出的「同位角相等、內錯角相等、同側內角互補」，並完整釐清平行四邊形、矩形（長方形）、菱形、正方形、箏形與梯形的邊角及對角線性質！

🎯 本單元核心學習目標

  • ✓熟練平行線三大截角性質（F 字同位角、Z 字內錯角、U 字同側內角互補）與閃電鋸齒角模型。
  • ✓掌握平行四邊形的四大性質與五大判別方法（特別是「一組對邊平行且相等」及「對角線互相平分」）。
  • ✓比較矩形（對角線等長）、菱形（對角線互相垂直）、箏形與正方形的對角線差異。
  • ✓熟練梯形兩腰中點連線長 $m = \frac{\text{上底} + \text{下底}}{2}$ 與面積公式 $\text{面積} = m \times h$。

生活化比喻：鐵軌英文字母密碼（F、Z、U）與四邊形 VIP 進化樹

怎麼一眼看出同位角、內錯角與同側內角？正方形為什麼是四邊形界的「全滿貫混血兒」？

🛤️ 比喻一：平行鐵軌上的英文字母密碼 F、Z、U

當兩條平行的鐵軌被一條斜向斑馬線（截線）切過時：

  • 字母 F（同位角）：都坐在十字路口的「右上角」相同方位 $\implies$ 角度相等！
  • 字母 Z（內錯角）：像閃電 Z 的兩個轉角，一左一右交錯在鐵軌內側 $\implies$ 角度相等！
  • 字母 U / C（同側內角）：關在同一個 U 型房間裡的兩個內角 $\implies$ 相加等於 $180^\circ$（互補）！

👑 比喻二：四邊形家族的「技能升級樹」

把平行四邊形當作基礎職業（對邊平行等長、對角線互相平分）：

  • 如果把四個角都扳正成 $90^\circ$ $\implies$ 進化成矩形（長方形，對角線變等長）。
  • 如果把四條邊都修成一樣長 $\implies$ 進化成菱形（對角線變互相垂直）。
  • 如果同時擁有矩形的 $90^\circ$ 與菱形的四邊等長 $\implies$ 終極進化成正方形（所有性質全包！）。

特殊四邊形對角線性質與梯形公式總表

會考最愛考的「對角線性質比較」與「梯形兩腰中點連線」

圖形名稱 對角線核心性質 重要面積與計算公式
平行四邊形 兩對角線互相平分（不一定等長、不一定垂直） 兩條對角線將平行四邊形分成四個面積相等的三角形。
長方形（矩形） 兩對角線互相平分且等長 對角線長 $= \sqrt{\text{長}^2 + \text{寬}^2}$。
菱形 & 箏形 • 菱形：兩對角線互相垂直平分（且平分內角）
• 箏形：一條對角線垂直平分另一條對角線 		凡是對角線互相垂直的四邊形（菱形、箏形、正方形）：$$\text{面積} = \frac{1}{2} \times \text{對角線 } d_1 \times \text{對角線 } d_2$$
梯形與等腰梯形 • 等腰梯形：兩底角相等，且兩對角線等長
• 兩腰中點連線必平行兩底 		兩腰中點連線長 $$m = \frac{\text{上底 } a + \text{下底 } b}{2}$$ 梯形面積 $= m \times \text{高 } h$

⚠️ 常見易錯觀念提醒（段考是非題必考陷阱！）

❌ 錯誤迷思 1：「一組對邊平行、另一組對邊相等的四邊形必為平行四邊形」

全台灣八年級最常被騙的幾何是非題！

✅ 正確觀念：反例就是「等腰梯形」（上下底平行、左右兩腰等長，但它不是平行四邊形）！必須是「同一組對邊既平行又相等」才必為平行四邊形！

❌ 錯誤迷思 2：「對角線互相垂直的四邊形必為菱形」

忘了還有對角線不互相平分的箏形或任意垂直對角線四邊形。

✅ 正確觀念：必須是「對角線互相垂直且平分」的四邊形才必為菱形！

經典題型演練（點擊展開逐步詳解）

涵蓋平行線折線角、平行四邊形座標頂點與等腰梯形應用

基礎題 平行四邊形在座標平面上的第四個頂點

1. 在座標平面上，已知平行四邊形 $ABCD$ 的三個頂點座標依序為 $A(1, 2)$、$B(4, -1)$、$C(7, 3)$，求第四個頂點 $D$ 的座標。

🔍 點擊展開逐步詳解▼

步驟 1：利用「平行四邊形對角線互相平分（對角頂點座標相加相等）」速解公式

因為 $AC$ 與 $BD$ 為對角線，中點相同，故：

$$A + C = B + D \implies D = A + C - B$$

步驟 2：分別計算 $x, y$ 座標

• $x_D = 1 + 7 - 4 = 4$

• $y_D = 2 + 3 - (-1) = 6$

答：$D(4, 6)$。

進階段考題 菱形對角線垂直平分與周長面積

2. 已知菱形 $ABCD$ 的兩條對角線長分別為 $\overline{AC} = 16\text{ cm}$、$\overline{BD} = 12\text{ cm}$，求此菱形的「面積」與「周長」分別為多少？

🔍 點擊展開逐步詳解▼

步驟 1：求菱形面積（對角線相乘除以 $2$）

$$\text{面積} = \frac{1}{2} \times 16 \times 12 = 96\text{ cm}^2$$

步驟 2：利用對角線互相垂直平分與畢氏定理求邊長

對角線的一半分別為 $8\text{ cm}$ 與 $6\text{ cm}$，構成直角三角形兩股，故菱形邊長 $= \sqrt{8^2 + 6^2} = 10\text{ cm}$。

周長 $= 10 \times 4 = 40\text{ cm}$。

答：面積為 $96\text{ cm}^2$，周長為 $40\text{ cm}$。

會考素養題 等腰梯形高與兩腰中點連線面積計算

3. 等腰梯形 $ABCD$ 中，$\overline{AD} \parallel \overline{BC}$，已知上底 $\overline{AD} = 6$、下底 $\overline{BC} = 16$，且腰長 $\overline{AB} = \overline{CD} = 13$。求此等腰梯形的兩腰中點連線長與梯形面積。

🔍 點擊展開逐步詳解▼

步驟 1：求兩腰中點連線長 $m$

$$m = \frac{6 + 16}{2} = 11$$

步驟 2：由上底兩端點向下底作垂直高 $h$，將下底多出的部分平分為左右兩段

左右兩小段底邊長 $= \frac{16 - 6}{2} = 5$。

由直角三角形畢氏數 $(5, 12, 13)$ 得梯形的高 $h = \sqrt{13^2 - 5^2} = 12$。

步驟 3：求梯形面積 $= \text{兩腰中點連線長} \times \text{高}$

$$\text{面積} = 11 \times 12 = 132$$

答：兩腰中點連線長為 $11$，面積為 $132$。
