勾股定理（畢氏定理）：直角三角形的三邊密碼

連結代數平方根與幾何圖形的橋樑！探索直角三角形兩股平方和等於斜邊平方（$a^2 + b^2 = c^2$）的永恆定律，並熟練斜邊上的高與坐標平面兩點距離公式。

🎯 本單元核心學習目標

  • ✓透過正方形面積拼貼直觀理解畢氏定理：$a^2 + b^2 = c^2$。
  • ✓已知直角三角形任意兩邊長，能快速求出第三邊長，並熟記四大黃金畢氏數。
  • ✓理解並計算直角三角形「斜邊上的高」公式 $h = \frac{ab}{c}$。
  • ✓應用畢氏定理求直角坐標平面上任意兩點 $A(x_1, y_1)$ 與 $B(x_2, y_2)$ 的直線距離。

生活化比喻：公園切西瓜走捷徑與地板方格磁磚

為什麼走對角線比較快？畢達哥拉斯在朋友家的地板磁磚看到了什麼？

🧱 比喻一：地板上的三塊正方形磁磚拼圖

直角三角形的三條邊分別往外鋪設正方形磁磚：

  • 兩條較短的直角邊（股，長 $3$ 與 $4$）向外鋪正方形，面積分別為 $3^2 = 9$ 與 $4^2 = 16$。
  • 最長邊（直角對面的斜邊，長 $5$）向外鋪正方形，面積剛好是 $5^2 = 25$！
  • 兩小正方形面積總和 $=$ 最大正方形面積（$9 + 16 = 25$）！

🏃 比喻二：長方形公園「走對角線捷徑」省幾公尺？

長方形公園往東 $60$ 公尺、往北 $80$ 公尺：

  • 沿外圍轉角走要 $60 + 80 = 140$ 公尺；走對角線斜邊只需 $\sqrt{60^2 + 80^2} = 100$ 公尺，省下 $40$ 公尺！
  • 常見整數畢氏數必背：$(3,4,5)$、$(5,12,13)$、$(8,15,17)$、$(7,24,25)$ 及其倍數！

核心公式表格與常見易錯提醒

從三邊長關係、斜邊上的高到直角坐標平面兩點距離公式

核心概念 數學公式與代數變形 適用條件與說明
畢氏定理本尊 $$a^2 + b^2 = c^2$$ $$c = \sqrt{a^2 + b^2}, \quad a = \sqrt{c^2 - b^2}$$ $c$ 必為直角（$90^\circ$）對面的最長邊（斜邊）。
斜邊上的高 $$h = \frac{\text{兩股相乘}}{\text{斜邊}} = \frac{a \times b}{c}$$ 由面積相等推導：$\frac{1}{2}ab = \frac{1}{2}ch \implies h = \frac{ab}{c}$。
坐標平面兩點距離 $$\overline{AB} = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$ 水平距離 $|x_1 - x_2|$ 與鉛直距離 $|y_1 - y_2|$ 構成兩股。

⚠️ 常見易錯觀念提醒

❌ 錯誤迷思 1：「看到直角三角形兩邊長 $3$ 和 $4$，第三邊只寫 $5$」

未確認 $4$ 是股還是斜邊！

✅ 正確觀念：若 $4$ 是股，斜邊為 $5$；若 $4$ 是斜邊，則另一股為 $\sqrt{4^2 - 3^2} = \sqrt{7}$！共有兩解！

❌ 錯誤迷思 2：「梯子頂端下滑 $4$ 公尺，底部也會往外滑動 $4$ 公尺」

誤把平方和關係當成線性加減關係。

✅ 正確觀念：必須利用「梯長（斜邊）不變」，分別用畢氏定理算出前後兩次的底部距離再相減！

✍️

經典題型演練（點擊展開逐步詳解）

涵蓋斜邊高、雲梯滑動應用題與坐標平面距離計算

基礎題 畢氏定理與斜邊上的高

1. 已知直角三角形 $ABC$ 中，$\angle C = 90^\circ$，兩股長分別為 $\overline{AC} = 5$、$\overline{BC} = 12$。求：(1) 斜邊 $\overline{AB}$ 的長；(2) 斜邊上的高 $\overline{CD}$ 的長。

🔍 點擊展開逐步詳解▼

步驟 1：求斜邊：$\overline{AB} = \sqrt{5^2 + 12^2} = 13$

步驟 2：求斜邊上的高：$\overline{CD} = \frac{5 \times 12}{13} = \frac{60}{13}$

答：(1) $13$；(2) $\frac{60}{13}$。

進階段考題 鋁梯靠牆滑動問題

2. 有一架長 $25$ 公尺的消防雲梯斜靠在垂直牆壁上，原本梯腳距離牆角 $7$ 公尺。若雲梯頂端沿牆壁下滑 $4$ 公尺，請問此時梯腳會往外滑移多少公尺？

🔍 點擊展開逐步詳解▼

步驟 1：求原本高度：$h_1 = \sqrt{25^2 - 7^2} = 24$ 公尺。

步驟 2：下滑 $4$ 公尺後新高度：$h_2 = 24 - 4 = 20$ 公尺，新底距 $d_2 = \sqrt{25^2 - 20^2} = 15$ 公尺。

步驟 3：求滑移距離：$15 - 7 = 8$ 公尺。

答：往外滑移 $8$ 公尺。

會考素養題 直角坐標平面上的兩點距離

3. 在直角坐標平面上，若學校位於點 $A(-2, 3)$，圖書館位於點 $B(6, -3)$，且每單位長代表 $100$ 公尺。請問學校到圖書館的直線距離是多少公尺？

🔍 點擊展開逐步詳解▼

步驟 1：套用兩點距離公式

$$\overline{AB} = \sqrt{[6 - (-2)]^2 + (-3 - 3)^2} = \sqrt{8^2 + (-6)^2} = 10 \text{ 單位長}$$

步驟 2：換算實際距離：$10 \times 100 = 1000$ 公尺。

答：$1000$ 公尺。
