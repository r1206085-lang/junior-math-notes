生活化比喻：平衡天平與超商購物找零

為什麼移項要變號？文字應用題怎麼找到「等號 $=$」放在哪裡？

⚖️ 比喻一：平衡天平（等量公理與移項法則）

方程式的等號「$=$」就像一座保持水平平衡的天平：

  • 左盤放「$3$ 袋神秘蘋果 $+$ $20$ 克砝碼」，右盤放「$350$ 克砝碼」：$$3x + 20 = 350$$
  • 兩邊同時拿走 $20$ 克砝碼，天平依然平衡：$$3x = 350 - 20 = 330$$（這就是為什麼 $+20$ 移到等號右邊會變成 $-20$！）
  • 接著把左右兩盤重量同時平分成 $3$ 等份，就知道每袋蘋果重 $x = 110$ 克！

🛒 比喻二：超商購物找零（抓出隱藏等式）

想像你在超商櫃檯結帳：

  • 拿一張 $500$ 元鈔票，買了 $4$ 杯同價位的珍奶（每杯設為 $x$ 元），店員找回 $260$ 元。
  • 收銀機鐵律：$$\text{付出去的錢} - \text{商品總價} = \text{找回的零錢} \implies 500 - 4x = 260$$
  • 只要抓住生活中「不變的總量關係」，方程式就自動浮現！

代數式化簡與五大必考應用題型公式表

掌握代數翻譯關鍵句，任何應用題都能迎刃而解

核心主題 數學公式與代數關係 未知數假設與列式範例
代數式化簡與去括號 $$-(ax - b) = -ax + b$$ $$m(ax + b) = max + mb$$ 括號前為負號時，去括號後括號內每一項都要變號！
購物找零與總價 $$\text{單價} \times \text{數量} = \text{總價}$$ $$\text{付出金額} - \text{總花費} = \text{找回金額}$$ 買兩種商品共 $14$ 件：若甲買 $x$ 件，則乙買 $(14 - x)$ 件。
成本、定價與折扣 $$\text{定價} = \text{成本} \times (1 + \text{加成}\%)$$ $$\text{售價} = \text{定價} \times \text{折數}$$ 成本 $x$ 元，加四成作為定價 $\implies 1.4x$；打八折出售 $\implies 0.8 \times 1.4x = 1.12x$。
分配與盈虧問題 $$a x + \text{剩餘 } m = b x - \text{不足 } n$$ 設帳篷有 $x$ 頂：每頂住 $6$ 人多 $10$ 人，每頂住 $8$ 人空 $1$ 頂 $\implies 6x + 10 = 8(x - 1)$。

⚠️ 常見易錯觀念提醒（化簡 vs. 解方程式）

❌ 錯誤迷思 1：「化簡代數式 $\frac{x+1}{2} - \frac{x-1}{3}$ 時直接同乘 $6$ 把分母消掉！」

把沒有等號的「一元一次式化簡」當成「解方程式」。

✅ 正確觀念：沒有等號時只能通分保留分母 $6$：$\frac{3(x+1)-2(x-1)}{6} = \frac{x+5}{6}$；只有含等號「$=$」的方程式才能左右同乘 $6$ 去分母！

❌ 錯誤迷思 2：「分數前面有減號時，分子忘記加括號變號」

計算 $\frac{3x+1}{2} - \frac{x-2}{2}$ 時寫成 $\frac{3x+1-x-2}{2}$。

✅ 正確觀念：分數線自帶隱形括號！減掉整個分子必須變號：$\frac{(3x+1)-(x-2)}{2} = \frac{2x+3}{2}$。

經典題型演練（點擊展開逐步詳解）

結合平衡天平與購物找零概念，挑戰三道必考代表題！

基礎題 超商購物找零與總量分配

1. 小明帶著一張 $500$ 元鈔票去文具店，買了每枝 $25$ 元的螢光筆與每枝 $15$ 元的原子筆共 $14$ 枝，結帳時店員找回 $210$ 元。請問小明買了幾枝螢光筆？

🔍 點擊展開逐步詳解▼

步驟 1：設買了 $x$ 枝螢光筆，則原子筆買了 $(14 - x)$ 枝

步驟 2：利用「購物找零」列方程式

$$25x + 15(14 - x) = 500 - 210$$

$$25x + 210 - 15x = 290 \implies 10x = 80 \implies x = 8$$

答：買了 $8$ 枝螢光筆。

進階段考題 宿營帳篷分配（盈虧問題）

2. 七年級舉辦隔宿露營，若每頂帳篷住 $6$ 人，則有 $10$ 人沒有帳篷可住；若每頂帳篷改住 $8$ 人，則剛好空出 $1$ 頂帳篷（其餘帳篷皆住滿 $8$ 人）。請問帳篷共有幾頂？學生共有幾人？

🔍 點擊展開逐步詳解▼

步驟 1：設帳篷有 $x$ 頂，由學生總人數相等列式

$$6x + 10 = 8(x - 1)$$

$$6x + 10 = 8x - 8 \implies 2x = 18 \implies x = 9$$

步驟 2：代回求人數：$6 \times 9 + 10 = 64$ 人。

答：帳篷 $9$ 頂，學生 $64$ 人。

會考素養題 成本、定價與百貨週年慶折扣

3. 某運動品牌的球鞋以成本加四成作為定價。在週年慶期間，老闆將定價打八折出售，結果每雙球鞋仍可賺得利潤 $240$ 元。請問這雙球鞋的「成本」與「定價」分別是多少元？

🔍 點擊展開逐步詳解▼

步驟 1：設成本為 $x$ 元，則定價為 $1.4x$ 元，售價為 $1.4x \times 0.8 = 1.12x$ 元

步驟 2：由「售價 $-$ 成本 $=$ 利潤」列式

$$1.12x - x = 240 \implies 0.12x = 240 \implies x = 2000$$

定價 $= 1.4 \times 2000 = 2800$ 元。

答：成本 $2000$ 元，定價 $2800$ 元。
